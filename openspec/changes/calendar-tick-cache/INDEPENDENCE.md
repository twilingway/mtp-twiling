# Independence

Владелец задачи меняет только чистый axis-ticks-cache, lightweight-calendar binding,
lightweight-calendar-grid, lightweight.ts, узкие календарные тесты и этот OpenSpec change. Остальные
модули, shared node_modules, build scripts, серверы, браузеры и Git-публикация не меняются. Исходный
axis-ticks и i18n форматирование остаются эталоном. Координатор управляет общей сборкой и
интеграцией; реализация не зависит от параллельных изменений других исполнителей.
