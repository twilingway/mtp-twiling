# Нижние панели инструментов телефона

## Why

Маленькие стрелки групп рисования неудобны для touch, а боковые выпадающие меню занимают график.

## What Changes

- Нажатие значка группы открывает нижнюю панель без отдельной стрелки.
- Сохраняются избранное, выбор, доступность инструментов и настройка долгого нажатия.
- Desktop использует прежнее меню; одиночные действия остаются быстрыми.

## Capabilities

### New Capabilities

- `mobile-drawing-sheets` — touch-меню групп рисования.

### Modified Capabilities

## Impact

DrawingToolbar, модальная нижняя панель, CSS и проверки взаимодействия.
