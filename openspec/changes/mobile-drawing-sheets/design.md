# Touch-меню

Проверенный на телефоне TradingView использует bottom0/fullwidth, строки 40 px, внутреннюю прокрутку
и max-height viewport−100. Наш sheet использует те же ориентиры, фон и safe area; фон затемняется и
блокируется, фокус возвращается. Существующий long-press checkbox сохраняется. Магнит получает
настоящий mobile OFF для обратимости; недоступные инструменты не включаются.
