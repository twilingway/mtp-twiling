# Proposal

## Why

В режиме всей истории 15083 свечи создают около 45000 Canvas-прямоугольников за кадр. Эксперимент
обратного отсечения перекрытых непрозрачных прямоугольников сохранил точные пиксели и ускорил
отдельный renderer на телефоне с 18,5 до 7,5 мс. Требуется проверить выигрыш в приложении.

## What Changes

- Сохраняется исходная геометрия и порядок native Candlestick renderer.
- При плотном размещении отсекаются полностью перекрытые пиксели; рисуются непересекающиеся остатки.
- Неподдерживаемые цвета, состояние Canvas и превышение бюджета используют прежний native путь.
- Обычный масштаб, OHLC, время, magnet, autoscale, индикаторы и данные остаются прежними.
- Для подключения используется ограниченное преобразование установленного SDK при сборке, с
  проверкой версии и хешей двух entrypoints; установленные файлы зависимости не редактируются.

## Capabilities

### New Capabilities

Нет: это оптимизация точной существующей отрисовки, без изменения наблюдаемой семантики.

### Modified Capabilities

Нет. Установлен `skip_specs: true`; правильность подтверждается differential-проверками native
пикселей и текущими сценариями графика.

## Impact

Чистое ядро отсечения, Canvas bridge, только основная Candlestick series, сборка и отдельные
проверки. Версия Lightweight Charts 5.0.9, Apache-лицензия и объявленные зависимости сохраняются.
Объём с промежуточной прозрачностью, другие серии и KLine используют прежний renderer. Проверка и
внедрение остаются локальными; публикация main отложена пользователем.
