# Design

## Context

См. proposal.md. Установленный SDK 5.0.9 рисует свечи через fillStyle/fillRect в bitmap scope.
Эксперимент подтвердил точность обратного отсечения непрозрачных прямоугольников. Сохраняем его
алгоритм, отделяя чистую геометрию от Canvas и сборки.

## Goals / Non-Goals

**Goals:** точные пиксели native свечей при плотном масштабе, ограниченная память и безопасный
возврат к исходной отрисовке до первого изменения основного canvas.

**Non-Goals:** изменение котировок, OHLC, autoscale, magnet, прозрачного объёма, других серий,
KLine, собственной геометрии свечей или публикация в main.

## Decisions

1. Чистый OpaqueRectCuller принимает целочисленные прямоугольники и идентификаторы цветов. Обратный
   проход использует битовую карту покрытия; остаются непересекающиеся вертикальные фрагменты,
   сгруппированные по цвету. История и рыночные данные в ядро не передаются.
2. Canvas bridge проверяет identity transform, source-over, alpha=1, отсутствие filter/shadow, sRGB.
   Разрешены только подтверждённые opaque CSS цвета и alpha=0. Неизвестное состояние, промежуточная
   прозрачность, нецелая геометрия и превышение бюджета вызывают native fallback. Запись и отсечение
   завершаются до первого рисования. Оптимизация включается только при spacing <1 CSS px и spacing ×
   horizontalPixelRatio <1 физического пикселя; остальное native.
3. Лимиты: bitmap до 4M пикселей, контролируемые массивы до 16MiB, включая временные массивы при
   росте; ограничены число команд/фрагментов, ширина прямоугольника и палитра. Суммарная работа
   ограничена 8M посещений column-words и проверяется при записи до прохода отсечения. Палитра
   сбрасывается между кадрами; resize/dispose освобождают ресурсы.
4. Build plugin преобразует SDK только в памяти, проверяя точные SHA256 обоих entrypoints и версию.
   Исходный renderer получает opt-in callback и исполняет прежнюю геометрию. Установленные файлы SDK
   и shared node_modules не меняются. Dev и production используют один plugin; при изменении SDK
   сборка останавливается. Apache notices сохраняются.
5. Только основная Candlestick series получает hook. Custom series отвергнута из-за изменения
   OHLC/magnet и необходимости переписать обычную геометрию. RGBA upload отвергнут по замерам.

## Risks / Trade-offs

- Скрытый clip нельзя прочитать из Canvas API → опора на проверенный полный native bitmap scope;
  differential-проверки с подложкой и всеми поддерживаемыми флагами.
- Частные методы SDK могут измениться → fail-closed hash/version guards и тест обоих bundles.
- Рост typed arrays и множество цветов → учёт временного выделения, ограниченная палитра, native
  fallback и освобождение при dispose.
- Микрозамер не равен FPS приложения → отдельная проверка интегрированного renderer, камеры,
  пикселей и времени кадров на физическом телефоне; честно сохранять ограничения замера.

## Migration Plan

Изолированная ветка от 70a2c6e, модульные проверки, независимое ревью, локальная сборка и проверка
desktop/телефона. Обновление активного DEV выполняет координатор после сохранения камеры и данных.
Откат — удалить opt-in hook и вернуть предыдущий проверенный DEV commit.
