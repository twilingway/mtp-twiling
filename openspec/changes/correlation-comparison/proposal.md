# Proposal

## Why

Для коэффициента корреляции пользователю нужно выбрать второй инструмент и увидеть результат по
подтверждённой истории обоих инструментов.

## What Changes

- Добавить выбор инструмента из списка котировок и сохранение его точного идентификатора.
- Загрузить свечи второго инструмента на интервале графика через чтение истории текущего профиля.
- Показывать коэффициент Пирсона с границами −1, 0, +1 и разрывами для неполных пар.

## Capabilities

### New Capabilities

- `correlation-comparison` — выбор второго инструмента, чтение истории и отображение коэффициента.

### Modified Capabilities

## Impact

Настройки индикатора содержат UID второго инструмента, источник свечи и длину окна. Дополнительный
ряд использует текущий клиент поставщика и кеш профиля. Расчётный вход хранится только в памяти.
