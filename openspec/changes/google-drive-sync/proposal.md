# Proposal

## Why

Настройки личного терминала должны переноситься между устройствами через собственный Google Диск
пользователя. Ключ банка и история котировок остаются только на устройстве.

## What Changes

- Добавить отдельное типизированное ядро авторизации и синхронизации без сервера.
- Передавать только разрешённые настройки/метаданные списка, рисунки, изображения и виды.
- Сохранять неизменяемые снимки и явно показывать конфликтующие ветви без потери данных.

## Capabilities

### New Capabilities

- `personal-drive-sync`: личная авторизация, безопасные снимки, большие изображения и разрешение
  конфликтов.

### Modified Capabilities

Нет.

## Impact

Новые `src/services/drive/`, тесты и документация. Существующие storage/controller/UI подключаются
отдельным шагом; новые зависимости не нужны. Google OAuth использует публичный Client ID и
единственный scope drive.appdata, уже разрешённые пользователем.
