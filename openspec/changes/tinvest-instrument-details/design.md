# Design

## Context

См. proposal.md. Клиентская PWA уже имеет авторизованный TBankClient.request и сериализованный
transport с отменой и retry 429. controller.sessionKey() возвращает текущую сессию без раскрытия
ключа.

## Goals / Non-Goals

Карточка не меняет торговые настройки, профиль, Drive, сервер или хранилище свечей. Исторические
финансовые отчёты вне доступного API; TTM/MRQ отображаются как снимок.

## Decisions

- Проверенный TBankClient из публичного sessionKey; WeakMap кеш на объект сессии, ключ UID/раздел.
  Результаты защищены owner/UID/generation/AbortSignal.
- Отдельный ленивый accordion на раздел. Статистика читает существующий DAY IndexedDB и DAY state
  только совпавшего UID, при недостаточном покрытии делает один годовой запрос. Сезонность
  запускается кнопкой, последовательно до шести годовых окон; запись в storage отсутствует.
- При наличии старой истории один короткий запрос за 10 дней подтверждает свежие завершённые свечи;
  известный API isComplete и неизвестный флаг локальных свечей отражены отдельными счётчиками.
- Успехи кешируются до 15 минут (показатели час), максимум 40 записей на сессию; in-flight запросы
  дедуплицируются с подсчётом подписчиков. Ошибки не кешируются.
- Нормализация unknown не превращает missing в 0. Нулевые proto3 fundamentals показаны как
  неоднозначные, поскольку scalar default не доказывает наличие показателя. Даты и валюты
  сохраняются.
- Математика чистая: полные дни, достаточные границы и отсутствие длинных пропусков. Месячная
  сезонность — среднее изменения цены от предшествующего закрытия по минимум трём полным
  наблюдениям; текущий месяц исключён.

## Risks / Trade-offs

- API не предоставляет дату обновления снимка fundamentals → явно указывать дату получения и
  доступный фискальный период.
- Локальный кеш не хранит isComplete → использовать только дни старше двух UTC суток, явно отличая
  покрытие от гарантии полноты источника.
- Приостановка торгов, сплиты и изменения состава сессий влияют на сравнение → консервативный фильтр
  покрытия, подпись без дивидендов и без самостоятельной корректировки сплитов.
- Официальный сайт документации недоступен инструменту → сверка по живому official GitHub proto и
  документирование источников.
