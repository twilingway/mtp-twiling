# Design

Замер начинается при запуске операции координатора. Переход этапа сохраняет длительность предыдущего
этапа по монотонным часам. При смене профиля данные замера очищаются.

Счётчик файлов меняется по мере успешной проверки или сохранения компонента снимка. Байты загрузки и
отправки учитываются после проверки файла или подтверждения записи. Повторно использованные файлы не
увеличивают счётчик отправленных байтов. Проверки без определённого объёма показывают этап и
прошедшее время.

Карточка обновляет время, пока выполняется операция, и сворачивает детализацию завершённой попытки.
Снимки, хеши и правила обработки конфликта сохраняют текущий формат.
