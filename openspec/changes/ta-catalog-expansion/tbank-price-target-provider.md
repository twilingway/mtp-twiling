# Данные для целей аналитиков Т‑Банка

Метод `GetInstrumentBy` принимает UID инструмента. Для акции источником целей становится
`GetConsensusForecasts`. Метод отдаёт общий список по страницам с нумерацией от нуля. Совпадение
проверяется по `assetUid` и валюте. Для расчёта нужны все страницы. Загрузка проверяет число
записей, размер и порядок страниц, уникальность UID и число запросов.
[GetInstrumentBy](https://developer.tbank.ru/invest/api/instruments-service-get-instrument-by) ·
[GetConsensusForecasts](https://developer.tbank.ru/invest/api/instruments-service-get-consensus-forecasts)

Банк обозначает `prognosisDate` как дату прогноза, `createdAt` как время создания записи,
`bestTargetPrice` как целевую цену на 12 месяцев. Горизонт рассчитывается как 12 календарных месяцев
от даты прогноза. Запись участвует в выборе после наступления обеих дат. Центральное значение
берётся из консенсусной цели банка. Число аналитиков выводится из трёх счётчиков при наличии полного
набора.
[Спецификация полей](https://developer.tbank.ru/invest/services/instruments/methods#getconsensusforecastsresponseconsensusforecastsitem)

Базой для процентного изменения служит биржевая дневная свеча инструмента за дату прогноза UTC с
признаком завершения. Если банк вернул валюту цены, она должна совпасть с валютой прогноза. Для
исторического момента внутри этого же дня закрытие ещё неизвестно. При пропуске даты, неполной свече
или истечении горизонта поставщик возвращает отсутствие данных.
[GetCandles](https://developer.tbank.ru/invest/api/market-data-service-get-candles) ·
[Формат исторических свечей](https://developer.tbank.ru/invest/services/quotes/marketdata#historiccandle)

Клиент загружает данные для видимого индикатора при смене инструмента и после истечения короткого
срока кэширования. Один проход по страницам можно разделить между несколькими запросами в одной
банковской сессии. При выходе из аккаунта, смене инструмента и снятии индикатора внешний вызов
отменяется. Вызов выполняется через существующую очередь REST-запросов Т‑Банка. Результат поставщика
хранится в памяти текущей вкладки.

На графике показываются три уровня из прогноза, процент от подтверждённой цены закрытия и дата
горизонта. Уровни с одной ценой имеют общую подпись. Метка исходной цены привязана к загруженной
свече соответствующего дня или к свечному периоду, который включает этот день. При короткой
истории видны уровни от начала доступного диапазона.
