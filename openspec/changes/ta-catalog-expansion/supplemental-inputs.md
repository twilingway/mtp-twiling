# Дополнительные рыночные данные

Запрос выполняется для видимого индикатора и текущего источника графика. Результат принадлежит
конкретной сессии, идентификатору инструмента, интервалу и окну истории. При смене источника запрос
отменяется, а поздний ответ исключается из расчёта. Переключение движка применяет уже загруженные
данные к новому адаптеру. Данные существуют в расчётном контексте до закрытия графика и не входят в
экспорт или хранилище котировок.

`ChartAdapter.updateTechnicalInputs()` принимает снимок дополнительных входов. Изменение открытого
интереса пересчитывает свой индикатор. Обновление объёмных входов пересчитывает индикаторы, которые
их используют. Свечи, камера и поток подписок остаются активны во время получения данных.

## Открытый интерес

Для линейных деривативов Bybit доступна история на 5м, 15м, 30м, 1ч, 4ч и 1Д. Запрашивается
`singleOpenInterest`, опубликованное биржей одностороннее значение в единицах базового актива. Точки
совмещаются по точной метке времени UTC. Нулевое наблюдение остаётся нулём. Если биржа не
предоставила точку, график оставляет пропуск. Первый непустой ответ можно показать до окончания
пагинации. Спот, другие биржи и интервалы за пределами списка получают явное состояние
недоступности.

[Bybit Open Interest](https://bybit-exchange.github.io/docs/v5/market/open-interest)

## Следующие источники

- Корреляция требует сохранённого идентификатора второго инструмента, отдельной отменяемой загрузки
  свечей на тот же интервал и совпадения меток времени. `MarketClient.candles()` меняет активные
  подписки, поэтому второму инструменту нужен отдельный метод чтения истории. При переключении
  инструмента или интервала оба входа подтверждаются заново.
- Price Target требует `GetConsensusForecasts`, сопоставления `instrumentUid` с `assetUid`,
  актуальной страницы прогноза и подтверждённого закрытия соответствующей даты. В обычном
  `GetForecastBy` согласованный результат приходит без даты и горизонта.
  [Т‑Банк](https://developer.tbank.ru/invest/services/instruments/methods#getconsensusforecastsresponseconsensusforecastsitem)
- Для рыночной ширины нужны наблюдения по историческому составу выбранного рынка. Расчёт со списком
  котировок терминала имеет другую область и не заменяет данные рынка.
