# Интеграция

- Основа `1953608` (0.3.10), ветка `feat/watchlist-color-flags`, отдельный worktree
  `artifacts/watchlist-flags-worktree`.
- Палитра: семь цветов с круглыми кнопками, текущий цвет выделен; снятие отметки доступно рядом.
  Нажатие флажка открывает только палитру, ПКМ — палитру и прежнее удаление строки.
- Флажок находится на левом краю, не меняет `MarketRow.color`, логотип, фон строки или эффекты цены.
  Для касания увеличена область кнопки, отметка без цвета видна при hover/focus и постоянно на
  touch.
- Фильтр «Все»/семь цветов со счётчиками строк; отдельная команда снятия всех отметок возвращает
  «Все». Выбранный график остаётся прежним, даже если фильтр скрывает его строку.
- Контракт для переноса: optional
  `ProfilePreferences.watchlistFlags: Record<string, WatchlistFlagColor>` и
  `watchlistFlagFilter: "all" | WatchlistFlagColor`. Экспорт `isWatchlistFlags`,
  `isWatchlistFlagFilter` и типов — `src/model/watchlist-flags.ts`; `isProfilePreferences` проверяет
  оба поля. Об этом сообщено владельцу Drive UI.
- Ключи: UID при наличии (`uid:<uid>`), иначе `legacy:<symbol>`; алиасы одного UID разделяют
  отметку, одинаковые symbol разных UID — независимы. Карта ограничена 5000 записями, ключ 200
  символами, неизвестные цвета и ключи отклоняются.
- Очередь по controller объединяет быстрые изменения после предыдущей записи. Callback после
  ожиданий и временная подписка отменяют действия при owner/import/revision, включая смену профиля
  туда и обратно до завершения ожидания. Меню также блокируется при переносе backup.
- Проверки: `pnpm check` — format/lint/typecheck/build и 228/228 тестов; `pnpm spec:validate` —
  12/12. Шесть новых тестов включают настоящий controller, storage и ручной backup A→C с сохранением
  B, гонки, UID/legacy/aliases, фильтр и изоляцию событий кнопки.
- Production-модули короче 500 строк; QuoteRow/InstrumentIcon извлечены в отдельный файл без смены
  публичного импорта InstrumentIcon.
- Канонический проект и стенд 5210 не изменены, сервер не запускался, публикация не выполнялась.
  Визуальная проверка desktop/touch и палитры у края окна остаётся координатору после интеграции;
  unit/DOM не выдаются за визуальный результат.
