# Design

## Context

KLine 9.8.12 Canvas._executeListener(fn) пропускает fn, когда уже назначен RAF. ResizeObserver может
вызвать _resetPixelRatio во время ожидающей отрисовки: nextPixelHeight обновляется, но изменение
bitmap теряется. Затем Canvas.update видит несовпадение размеров и только повторяет CSS; новый
ResizeObserver не возникает. Диапазон, тики и преобразование координат правильные, видимые метки
устарели.

## Goals / Non-Goals

**Goals:** восстановить нативную отрисовку без изменения данных и режима оси.

**Non-Goals:** переписывать библиотеку, менять зависимости или приватное состояние; изменять
загрузку недельной истории.

## Decisions

Наблюдать публичные DOM canvas после создания панелей. После двух RAF сравнивать bitmap с CSS × DPR
с допуском округления. При устойчивом несовпадении временно увеличить публичную фиксированную ширину
оси на один пиксель и через два RAF вернуть актуальную штатную ширину. Это вызывает новый нативный
ResizeObserver для обеих осей и основной области.

Повторять штатный resize недостаточно: CSS уже совпадает с требуемыми размерами. Изменять приватные
поля запрещено; изменение диапазона тоже не устраняет размерную гонку и сбрасывает ручной масштаб.

## Risks / Trade-offs

- На два кадра ширина plot отличается на один пиксель → восстановление запускается только при
  подтверждённом несовпадении после двух кадров.
- Нулевые размеры скрытого графика → пропуск проверки до следующего resize.
- Уничтожение адаптера или responsive-изменение ширины во время восстановления → отмена RAF,
  disconnect observer; возврат актуальной ширины из адаптера.
- Подтверждение браузером собранного исправления → отдельный свежий QA после интеграции
  координатором; текущий сервер заморожен.
