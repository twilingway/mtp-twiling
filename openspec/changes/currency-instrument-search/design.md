# Design

## Context

Live аудит 25.11.2026 19:57–20:03 UTC подтвердил 29 валют и тип currency/INSTRUMENT_TYPE_CURRENCY.
USDRUB_TOM не найден сервером, USD000UTSTOM найден. Одноимённые валюты CETS и CNGDOTC имеют разные
UID.

## Goals / Non-Goals

**Goals:** доступный валютный поиск без изменения реального symbol/UID, частичное обновление старого
кэша, совместимые optional поля.

**Non-Goals:** криптовалюты, изменение котировок и источников, миграция истории, сервер и аккаунты.

## Decisions

- `Catalog.currencies?: CatalogInstrument[]` отличает старый/неуспешно обновлённый кэш от успешно
  полученного пустого каталога. Прежние обязательные каталоги сохраняют формат.
- Загрузка каталога вынесена из TBankClient в небольшой модуль. При свежем legacy кэше запрашивается
  только Currencies; ошибка не бросается в клиент и поле остаётся отсутствующим для последующего
  запуска.
- `currency` расширяет CatalogInstrument.kind, MarketRow.type и union поискового фильтра.
  Нормализация сохраняет instrumentKind, exchange и realExchange для классификации и подписи
  источника.
- Чистый поисковый helper сопоставляет алиасы и выбирает серверный query. Алиас не записывается в
  инструмент. UID остаётся ключом дедупликации.
- Backup schemaVersion 1 принимает новый тип currency; Drive allowlist уже переносит type. Новые
  каталоговые поля в backup не нужны.

## Risks / Trade-offs

- Одинаковые тикеры принадлежат разным источникам → список показывает classCode и MOEX/дилер, без
  автоматического выбора UID.
- Каталог Currencies может быть временно недоступен → основной запуск продолжается, fallback поиск
  классифицирует валюты, следующий запуск повторяет upgrade.
- Root владеет Watchlist/ChartPanel → их подписи валют интегрируются координатором отдельно.
