# Расчёт индикаторов с разворотными точками

## ADDED Requirements

### Requirement: Подтверждение фракталов и разворотных точек

Расчёт SHALL возвращать координату точки и отдельно индекс её подтверждения. Для фрактала требуется
строгий экстремум внутри заданного окна, по умолчанию из пяти свечей. Zigzag SHALL соединять
чередующиеся экстремумы при достаточном относительном изменении цены и обновлять последнюю точку при
более выраженном экстремуме того же типа.

#### Scenario: Правый край истории

- **WHEN** максимум или минимум свечи превосходит соседние, но справа пока меньше свечей, чем
  требуется
- **THEN** расчёт не возвращает подтверждённую точку этой свечи
- **AND** после появления полного правого окна координата результата указывает на центральную свечу

#### Scenario: Слабый разворот Zigzag

- **WHEN** после подтверждённого максимума глубина снижения меньше порога
- **THEN** новый сегмент не появляется
- **AND** следующий более высокий подтверждённый максимум заменяет прежнюю последнюю точку

### Requirement: Геометрия по подтверждённым опорам

Расчёт SHALL вычислять уровни коррекции из двух опор, расширение из трёх и медианы Original, Schiff,
Modified Schiff, Inside из трёх. Для числовых координат используются линейная шкала цены и индексы
баров.

#### Scenario: Три опоры восходящей волны

- **WHEN** начальная цена 100, следующий максимум 130, а цена отката 110
- **THEN** расширение с коэффициентом 1 равно 140
- **AND** медиана Original проходит от первой опоры через середину двух следующих

### Requirement: Опоры трендовой линии и пробой

Расчёт SHALL применять размеры окон и пороги по ATR отдельно для малых и больших разворотов. Для
заданной линии пробой наступает после заданного числа последовательных закрытий по внешней стороне
линии.

#### Scenario: Прерванная последовательность закрытий

- **WHEN** порог равен трём и между двумя сериями выходов за линию встречается закрытие с внутренней
  стороны
- **THEN** серия закрытий для подтверждения пробоя начинается заново

### Requirement: Ценовые уровни одного периода

Расчёт SHALL возвращать OHLC из полного набора свечей периода и POC, VAH, VAL из предоставленных
строк профиля. Без готовых строк профиля OHLC доступны отдельно.

#### Scenario: Инструмент без профиля объёма

- **WHEN** переданы свечи с полными OHLC, а строки объёма отсутствуют
- **THEN** результат содержит цены открытия, максимума, минимума и закрытия периода
- **AND** значения POC, VAH и VAL отсутствуют
