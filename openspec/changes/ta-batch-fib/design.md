# Design

## Context

Встроенный контракт графиков принимает временные ряды. Индикаторам этой группы также нужны отдельные
метки, уровни цены, сегменты и лучи. Расчёт отдаёт конечные координаты в индексах баров и ценах, где
это требуется для отрисовки.

## Goals / Non-Goals

Цель — проверить публично описанную математику отдельно от отрисовки. Подбор всех опор TradingView,
проекции Zigzag на незакрытой свече, ранжирование автоматических трендовых линий и сбор
внутрипериодных профилей объёма остаются задачами интеграции.

## Decisions

- Каждая разворотная точка содержит индекс бара, время бара, цену и индекс подтверждения. Фрактал
  требует строгого экстремума с обеих сторон. Zigzag допускает равное значение справа и заменяет
  последнюю опору при движении в ту же сторону до более выраженного экстремума. Данные для двойного
  экстремума свечи не задают порядок сделок. При одновременных кандидатах используем одну опору с
  приоритетом подходящего продолжения текущего движения, при старте первой идёт верхняя. Для
  противоположной опоры нужно направленное движение и порог от абсолютной цены предыдущей опоры. При
  нулевой цене относительный порог неопределён, принимается только направленный разворот с нулевой
  настройкой порога. Пропуск OHLC разрывает траекторию.
  [Zigzag](https://www.tradingview.com/support/solutions/43000591664-zigzag-indicator/),
  [фрактал Вильямса](https://www.tradingview.com/support/solutions/43000591663-williams-fractal-indicator/)
- Auto Fib получает подтверждённые опоры извне. Для Retracement нужны две, для Extension три. Уровни
  повторно используют функцию цены существующих инструментов рисования MTP. Публичные описания
  объясняют коэффициенты и ввод глубины, точный выбор опор требует отдельной сверки.
  [Коррекция](https://www.tradingview.com/support/solutions/43000585089-auto-fib-retracement/),
  [расширение](https://www.tradingview.com/support/solutions/43000612397-auto-fib-extension/)
- Вилы получают три опоры. Медиана строится по описанной геометрии выбранного варианта. Параллельные
  пары смещаются пропорционально выбранным коэффициентам от максимального вертикального расстояния
  крайних опор до медианы. Для Inside, где третья опора лежит на медиане, берётся расстояние второй
  опоры. Это правило MTP задаёт симметричные уровни.
  [Вилы](https://www.tradingview.com/support/solutions/43000657911-auto-pitchfork/)
- Для Auto Trendlines сначала возвращаем опоры 5/5 и 25/25 за последние 5000 баров, проверяя пороги
  2× и 5× ATR(14) в первой опоре. Отдельная функция принимает две заданные опоры и находит пробой по
  последовательным закрытиям. Полный выбор пар, дополнительные касания и рейтинг линий остаются
  этапом интеграции.
  [Автоматические трендовые линии](https://www.tradingview.com/support/solutions/43000741165-auto-trendlines/)
- Auto Key Levels принимает свечи одного периода и готовые смежные ценовые строки объёма. POC
  берётся по середине строки с максимальным объёмом, при равном максимуме предпочтение нижней
  строке. Это правило MTP для равного максимума. От POC расширяем зону к строкам с большим объёмом,
  далее к ближайшей и при равенстве к верхней. Добавление прекращается, если следующая строка
  превышает оставшийся целевой объём. Для POC и границ зоны необходим источник готовых строк с
  объёмом по цене.
  [Ключевые уровни](https://www.tradingview.com/support/solutions/43000783958-auto-key-levels/),
  [профиль объёма](https://www.tradingview.com/support/solutions/43000502040-volume-profile-indicators-basic-concepts/)

## Risks / Trade-offs

Рассчитанные точки Zigzag подтверждаются с задержкой, а последняя меняется при более выраженном
экстремуме. Адаптер использует индекс подтверждения и заново вычисляет геометрию при обновлении
исторических свечей. Для приближённых уровней объёма по одной свече понадобилась бы модель
распределения объёма внутри диапазона. Текущий расчёт требует входных строк профиля.
