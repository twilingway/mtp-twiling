# Верхняя панель

Общий flex-scroller без переноса сохраняет высоту 42 px. Pill 128×28 содержит отдельные кнопки
поиска и вида графика. Dropdown выводится portal/fixed с поддержкой fullscreen и закрывается при
прокрутке. Единственный аватар слева открывает объединённое меню; PWA install DOM ids остаются
смонтированы. Recovery barrier сохраняет доступ к аккаунту. Мобильные интервалы — bottom sheet с
фокусом, Escape, прокруткой и полной областью trigger. Меняются display labels, а не IDs/ms/API.

Меню аватара использует компактную шапку профиля и две верхние строки навигации с иконками закладки
и слоёв. Они вызывают существующий panel.select без переключения в закрытое состояние; мобильный
режим передаётся только на телефоне. Группы ниже содержат существующие настройки графика, историю,
часовой пояс, тему, язык, единый вход в диалог аккаунта и помощь. Вход в аккаунт сопровождается
пояснением про подключение, облако и перенос. Отдельный переключатель инструментальной панели не
добавляется: у приложения пока нет такого управления. PWA leaf остаётся смонтированным в группе
помощи при закрытом меню. Состояние раздела вычисляется из существующих настроек и mobilePanelOpen;
новые хранилища или миграции не требуются.
