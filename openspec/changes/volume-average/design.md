## Context

Встроенный «Объём» уже рисуется как отдельная шкала Lightweight Charts и панель `volume_pane` в
KLineChart. Оба адаптера получают свечи текущего интервала с числовым объёмом.

## Goals / Non-Goals

- Дополнительная линия либо скрыта, либо показывает простое среднее по объёму.
- Разделить средние цены и объёма. Сохранить правила раскраски столбцов и управление панелями.

## Decisions

- Хранить `chartSettings.volumeAverage` с флагом `enabled` и целым `period`. Для прежних настроек по
  умолчанию `false` и `20`. Диапазон 1–10000 соответствует существующим настройкам периодов
  технических индикаторов.
- Считать сумму объёмов за окно текущей свечи и предыдущих свечей, разделённую на длину окна. При
  недостатке истории оставлять начало без линии. Обновлять текущую точку по живому объёму.
- Подгружать старые свечи в фоне, если включённой средней не хватает свечей. Готовность сохранённого
  окна графика зависит от его покрытия. Период влияет на конфигурацию адаптера и сохраняется через
  редактор настроек.
- Рисовать среднюю на той же шкале, используя настройки линии индикатора «Объём». Скрытие объёма
  скрывает обе серии. Включение средней не создаёт ещё одну техническую панель.

## Risks / Trade-offs

- Старые копии без поля читаются с исходными настройками. Для чтения переносимого снимка с новым
  полем нужна версия с поддержкой средней.
- При отсутствии части истории линия начинается с первой свечи, для которой получено полное окно.
