# Verification

224 профильных Yandex-теста проходят. Покрыты exact proof codec и подмена валидного legacy/test с
тем же ID до повторного inspection и автоматического publish, metadata rewrites, cold retry,
пределы, итеративный граф из 10 000 файлов и события scheduler.

Независимый reviewer подтвердил исправление обоих воспроизведений P1. Без исходного proof данные
сохраняются; новое чтение старого UUID не создаёт доказательство принятия.

UI-группы и состояния удаления проверены на изолированных синтетических метаданных. Эти проверки не
выдаются за удаление из реального аккаунта. Проверки исходников и синтетического транспорта не
использовали пользовательские credentials и не меняли его облако.

Два коротких wall-clock теста зависели от скорости криптографии Windows. В release они используют
управляемые часы после достижения DELETE/refresh gate; прошли четыре параллельных stress-повтора и
полный coordinator-пакет. Production deadline не менялась.
