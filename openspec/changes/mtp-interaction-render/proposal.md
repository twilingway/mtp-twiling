# Proposal

## Why

На физическом Android обычный тяжёлый MTP при шаге 1,015 px не получает растровый preview.
Выключенный MTP продолжает сканировать экстремумы на каждом кадре, особенно при Fit.

## What Changes

- Расширить ограниченный точный растровый слой на тяжёлый MTP с обычным шагом.
- Сохранять захваченное покрытие небольшого сдвига и возвращать точные линии после жеста.
- При выключенных периодах завершать draw/autoscale до обхода данных и canvas.

## Capabilities

### New Capabilities

- `mtp-interaction-render`: точное представление тяжёлого MTP при жестах и отсутствие работы
  отрисовки выключенного MTP.

### Modified Capabilities

Нет.

## Impact

Только модель MTP и её растровый слой, проверки и OpenSpec. Формулы, периоды, источники данных,
график свечей, React, глобальный DPR и зависимости сохраняются.
