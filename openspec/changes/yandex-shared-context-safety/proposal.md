# Proposal

## Why

Браузер и PWA одного профиля разделяют журнал Яндекса, но имеют отдельное состояние интерфейса.
Воспроизведение показывает, что неизменённое старое окно публикует свои настройки поверх новой
версии другого окна.

## What Changes

- Отслеживать принятую базу отдельно для каждого открытого окна.
- До экспорта неизменённого старого окна восстанавливать его интерфейс из локального хранилища.
- При самостоятельных изменениях двух окон показывать сравнение без автоматической отправки.
- Сохранить явный выбор направления для неизвестной истории.

## Capabilities

### New Capabilities

- `yandex-shared-context-safety`: защита обмена между окнами с общим локальным журналом.

### Modified Capabilities

Нет.

## Impact

Координатор Яндекса, общий host восстановления интерфейса и source-тесты. Облачный формат и OAuth не
меняются.
