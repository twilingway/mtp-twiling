# Chart Layout Synchronization

## ADDED Requirements

### Requirement: Choose and resize a chart layout

Рабочая область SHALL поддерживать от одного до шестнадцати графиков с несколькими вариантами
расположения при двух и более графиках.

#### Scenario: Change arrangement

- **WHEN** пользователь меняет расположение при том же количестве графиков
- **THEN** инструменты и настройки панелей сохраняются

#### Scenario: Save divider size

- **WHEN** пользователь передвигает разделитель и перезагружает страницу
- **THEN** размеры восстанавливаются для выбранного варианта в этом браузере

### Requirement: Link individual chart properties

Инструмент, интервал, перекрестие, время и диапазон дат SHALL включаться независимо. Изначально
переключатели выключены.

#### Scenario: Link one property

- **WHEN** включена связь по интервалу и пользователь меняет интервал в одной панели
- **THEN** другие панели применяют доступный интервал и сохраняют собственные инструменты

#### Scenario: Crosshair across different instruments

- **WHEN** включена связь перекрестия и пользователь наводит указатель на свечу
- **THEN** другие панели показывают перекрестие в этот момент по цене собственной свечи, если она
  есть и видна

#### Scenario: Move or scale the visible dates

- **WHEN** пользователь изменяет видимый участок при включённой связи по времени или диапазону
- **THEN** связь по времени устанавливает правую границу в других панелях с прежним масштабом, а
  связь по диапазону переносит обе границы в пределах доступной истории
