# Устройство раскладок

Модель определяет прямоугольники панелей для миниатюры, CSS-сетки и разделителей. На узком экране
панели расположены вертикально и прокручиваются. Слоты сохраняют ключи при смене расположения.

Настройки хранятся по локальному профилю. Размеры запоминаются отдельно для варианта и ширины
экрана. При включении связи по инструменту или интервалу источником служит активный график.
Дальнейшее пользовательское действие передаётся от графика, в котором оно произошло. Адаптеры
применяют полученные команды без повторной рассылки. При смене профиля отменяются незавершённые
команды.

Связь по времени выравнивает правую временную границу с сохранением масштаба получателя. Связь по
диапазону переносит обе границы и имеет приоритет при включении обоих переключателей. Масштаб цены
принадлежит каждому графику. Перекрестие передаёт время, а цена берётся из собственной свечи окна.
