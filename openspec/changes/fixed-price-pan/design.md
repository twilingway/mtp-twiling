# Design

## Context

ChartGestures пропускает нативное перемещение в оба движка. Автомасштабирование цены остаётся
включённым. Текущий пользовательский TradingView имеет активное autoScale:false (наблюдение только
для чтения, 25.11.2026).

## Goals / Non-Goals

**Goals:** Фиксировать фактический текущий масштаб до нативного начала перемещения; сохранять
обычные события движков и редактирование объектов.

**Non-Goals:** Изменение зависимостей, общего формата камеры, календаря, переноса камеры между
инструментами и начального размещения.

## Decisions

- Успешный импорт увеличивает отдельную chartRevision ровно один раз. Она входит в lifetime и
  matches guard canvas независимо от нормализованного renderConfig, поэтому импорт того же layout
  применяет incoming view после данных. Некорректный/неуспешный импорт и обычные настройки toolbar
  ревизию не меняют.

- render-config выделяет только нативные settings/effective indicators в детерминированный ключ.
  useMemo сохраняет конфигурацию при lastTools/favorites/magnet/stay/templates и настройках
  React-оболочки. drawingsHidden отдельно запускает redraw и использует текущий state из paint
  callback.
- Публичные Lightweight applyOptions и scrollToPosition ставят команды в RAF, поэтому сразу читать
  их геометрию нельзя. Восстановление ждёт первого layout/fit, вычисляет конечный rightOffset из
  saved spacing/anchor и ставит один applyOptions. Size callback во время setData защищён guard;
  getView не возвращает ещё не применённую камеру. Regression-модель публичного API теперь также
  откладывает setters до RAF и вызывает синхронный size callback из setData.

- Импорт валидируется до изменений редактирования/сессии, затем завершается запись прежней разметки
  и вида. Исходящий адаптер получает persistView:false, который проверяют controller.saveView и
  общий cleanup helper saveAdapterView. Ошибка storage.importBackup возвращает прежний флаг;
  успешный commit оставляет старый адаптер исключённым из сохранения.
- resetSharedChartCamera после commit удаляет только shared records и память с точным owner,
  сохраняя входящие per-symbol views и другие профили. Оркестрация импорта выделена в
  controller-import.ts для лимита 500 строк контроллера.

- ChartView.camera хранит CSS-pixel barSpace и знаковый rightOffsetBars. Общий record изолирован
  профилем/движком/таймфреймом и содержит исходный symbol. Между инструментами переносится только
  camera; для повторного открытия того же инструмента сохраняется anchor. Старые from/to,
  barSpace/offsetRight продолжают читаться.
- Lightweight использует публичные scrollPosition/options().barSpacing. KLine getter расстояния
  справа обрезает отрицательные значения, поэтому signed offset вычисляется из публичной координаты
  последней свечи и ширины области; setOffsetRightDistance принимает знаковую дистанцию. Публичные
  координаты KLine округляются до пикселя: возможна погрешность менее одного пикселя.
- PendingChartView откладывает запрос до непустых данных и ширины области. Lightweight
  восстанавливает после initial fit; KLine — по OnDataReady после fit. Начальное восстановление и
  сохранение viewport при prepend принадлежат chart-lifecycle, дублирующий history RAF и initial
  storage.loadView удалены.
- History epoch проверяет captured symbol/timeframe/uid/rangeDays; canvas factory и callbacks
  проверяют owner/viewKey/uid и cancellation. Основной controller использует selectionEpoch вокруг
  асинхронных сохранений, изменения ширины панели не отменяют выбор инструмента.

- Опциональные beginPan/endPan адаптера отделяют управление жестом от библиотеки. Цена остаётся в
  ручном режиме после отпускания, иначе сразу вернётся нежелательное автомасштабирование.
- Lightweight Charts предоставляет публичные getVisibleRange/setVisibleRange и autoScale:false.
- Фиксация выполняется только после движения больше 3px; простой клик не меняет режим оси. KLine
  после переключения оси восстанавливает исходный main-pane mousedown для продолжения уже начатого
  нативного жеста. Сброс выполняет штатный двойной клик ценовой оси.
- focusPoints центрирует выходящие за видимую область опорные точки с сохранением ширины окна.
  Lightweight также переносит ценовой диапазон без изменения его ширины. KLine сохраняет текущую
  шкалу цены при горизонтальном переносе, но не перемещает вертикально далёкие точки: публичного
  setter диапазона нет.
- KLineChart 9.8.12 не предоставляет публичного setPriceRange или отключения autoCalc; registerYAxis
  позволяет лишь создавать подписи. Используется публичный getDom ценовой оси и штатный нулевой по
  вертикали mouse-жест. Смещение X на 6px проходит нативный порог движения 5px, Y сохраняется:
  штатная ось копирует текущий диапазон в ручной режим с коэффициентом 1:1. Приватные поля и заранее
  заданные границы цены не используются.
- Перемещение графика не получает pointer capture приложения. Глобальные pointerup/cancel и blur
  завершают только состояние курсора; транзакции рисунков остаются прежними.

## Risks / Trade-offs

- [KLine не имеет прямого публичного API] → DOM bridge изолирован, проверяется на закреплённой
  версии и требует браузерного smoke обоих движков; ось уже 14px или скрытая безопасно пропускается.
- [Синтетические события оси] → только синхронная короткая последовательность до первого нативного
  движения, без изменения Y и доступа к внутренностям; исходный main-pane mousedown
  восстанавливается.
- [Потеря фокуса при удержании] → сброс состояния pan через blur; восстановление автомасштаба
  выполняется штатным двойным кликом ценовой оси.
