# Задачи

## 1. Модель клиента

- [x] 1.1 Повторно использовать обычный ID и отдельный тестовый слот. Проверить параллельную
      инициализацию и переключение режима.
- [x] 1.2 Хранить две последовательные версии и сравнивать изменения. Проверить конкуренцию,
      повреждённую последовательность, повтор записи и восстановление.

## 2. Облачный транспорт и переход

- [x] 2.1 Подключить двоичный транспорт к координатору с проверкой допуска к записи. Покрыть
      конкуренцию, повторное чтение после неопределённого ответа и конфликт при загрузке.
- [x] 2.2 Проверить полную копию старых снимков, чтение скачанного файла, целостность изображений и
      отмену плана при поздней записи на тестовых данных.
- [ ] 2.3 Подтвердить условную запись и CORS на техническом файле в реальном браузере.

## 3. Очистка

- [x] 3.1 Проверить вычисление плана, порядок удаления, остановку при позднем файле и отчёт об
      удалении на тестовом транспорте.
- [ ] 3.2 Подтвердить остановку старых клиентов и завершение их запросов. Подключить предварительный
      просмотр и реальное удаление после доказанного переноса.
- [ ] 3.3 Проверить перенос и очистку отдельного тестового аккаунта, два обычных клиента и общий
      тестовый слот.
