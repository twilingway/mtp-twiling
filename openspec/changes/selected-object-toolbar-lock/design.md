# Design

## Context

Главная кнопка вызывает глобальную команду без selectedObject. При клике по пустому графику
ChartSurface очищает selectedObject; хранимый lockTarget при этом сохраняется и продолжает
определять глобальную команду.

## Goals / Non-Goals

Главная кнопка отражает актуальное выделение рисунка или изображения. Стрелка и мобильное нажатие
открывают глобальное меню. Индивидуальная блокировка индикаторов не вводится.

## Decisions

- Подписать глобальное меню «Для всех объектов: блокировка»; оставить его три пункта, проверяемое
  состояние, цвет и галочку.
- Без выбранного drawing/image показывать недоступную основную кнопку с подсказкой «Выберите объект
  для блокировки».
- При глобальной блокировке рисунков индивидуальную кнопку отключать, показывать закрытый замок и
  объяснение перехода в меню.
- Команда захватывает текущий идентификатор и scope и повторно проверяет их перед изменением; снятие
  или смена выделения отменяет устаревшее действие. Изменение проходит через историю редактирования.
- Мобильный split сохраняет прежнюю семантику открытия меню даже при недоступном индивидуальном
  действии.

## Risks / Trade-offs

Прямое повторение глобального режима главной кнопкой заменяется действием над выделением по запросу
пользователя. Все общие действия доступны через стрелку, а на мобильном — обычным нажатием.
