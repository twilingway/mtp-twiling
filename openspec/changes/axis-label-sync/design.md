# Общий цикл шкал

## Context

Отсчёт опрашивает положение раз в 50 мс, изображения — раз в 32 мс. Метки объектов ожидают отдельный
React-рендер после canvas-события.

## Decisions

- React передаёт адаптеру логические значения и календарный текст. Адаптер проецирует их в своём
  нативном цикле.
- Последняя цена сохраняет исходную ценовую линию. Дублирующая метка скрывается только пока нативный
  составной блок доступен.
- Метки рисунков передают время, цену и стиль без DOM-координат.
- Изображения применяют transform непосредственно по уведомлению проекции.
- KLine перерисовывает передний слой из приватного нативного draw-hook, поскольку перетаскивание
  ценовой оси не отправляет публичные события прокрутки или масштаба. Этот hook не добавляет
  пользовательский индикатор, расчётные значения или собственный цикл кадров.

## Risks / Trade-offs

- Отрисовщики шкал, фабрики слоёв и палитра KLine выделены в отдельные модули, чтобы сохранить лимит
  размера адаптеров и отделить отрисовку от сохранения камеры.
- `lightweight.ts` занимает 503 физические строки с пустыми и проходит существующий lint-лимит.
  Дополнительное выделение жизненного цикла камеры отложено до отдельной задачи; новые отрисовщики
  шкал уже находятся в отдельных модулях.

- Адаптер создаётся асинхронно. Первая нативная отрисовка повторно передаёт актуальные логические
  метки, если компонент уже смонтирован.
- Смена владельца или адаптера должна сбрасывать только данные прежнего графика.
