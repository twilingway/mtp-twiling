# Design

## Context

Дневные, недельные и месячные уровни используют подтверждённые свечи источника или проверенную
непрерывную последовательность свечей графика. Профиль использует фактические сделки OKX Spot.

## Decisions

- У каждого набора свой режим показа. По умолчанию включены OHLC и профиль текущего и предыдущего
  дня. Можно одновременно включить неделю, месяц и скользящий календарный интервал. При совпадении
  цен дневные линии отрисовываются перед недельными и месячными. Префиксы соответствуют виду
  периода, например `dO` и `pdPOC`.
- Данные профиля должны покрывать запрошенный полуоткрытый период целиком. Для текущего периода
  граница определяется последним подтверждённым снимком сделок внутри интервала последней свечи.
  Если предыдущий период завершён, требуется покрытие до его границы.
- Сделки распределяются в интервалы целого числа минимальных шагов цены. Размер профиля по умолчанию
  24 строки, целевая доля зоны стоимости 70%. Пустые ценовые строки появляются только в доказанном
  диапазоне сделок. Свечи поставляют уровни цен отдельно.
- Переключатель предлагает интервалы с доступным календарным источником. Якоря по отчётам,
  дивидендам и сплитам требуют отдельного источника событий.
- Страница сделок OKX загружается ограниченными порциями. При превышении лимита поставщик может
  доказать только суффикс окна. Этот суффикс используется для меньших полностью известных периодов.
