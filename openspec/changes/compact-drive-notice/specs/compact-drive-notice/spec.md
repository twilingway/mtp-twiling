# Spec Delta

## ADDED Requirements

### Requirement: Компактный статус паузы Google Диска

Главный экран SHALL показывать причину паузы Google Диска в одной строке с переходом в настройки.
Статус SHALL отмечать несинхронизированные правки, если они есть, и сообщать о конфликте версий
доступным текстом.

#### Scenario: Истёк срок доступа

- **WHEN** в связанном профиле истёк доступ при включённой автосинхронизации
- **THEN** главный экран показывает короткий статус с причиной паузы
- **AND** после нажатия открывается вкладка Google Диска

#### Scenario: Есть локальные изменения и конфликт версий

- **WHEN** для синхронизации требуется выбрать версию и на устройстве есть правки
- **THEN** строка сообщает о конфликте и наличии неотправленных изменений

#### Scenario: Возобновление обмена

- **WHEN** причина паузы устранена и координатор возобновил обмен
- **THEN** строка паузы освобождает место рабочей области
