# Proposal

## Why

Телефонный жест рисования требует нескольких касаний, а долгое удержание объекта открывает меню
поверх его перетаскивания. Вертикальная шкала в нескольких графиках ошибочно отдаёт жест прокрутке
страницы.

## What Changes

- Линия и прямоугольник создаются одним touch down → drag → up.
- Удержание рисунка не открывает ПКМ; правый клик мыши и OHLC удержание свечи сохраняются.
- Touch маркеры получают размер 26 px и область попадания 44 px.
- Компактный четырёхстрелочный блок навигации удаляется.
- Ценовая шкала принимает вертикальный touch независимо от количества графиков; область графика
  сохраняет прокрутку workspace.

## Impact

Обработчики ChartSurface, ChartNavigation, чистые helpers touch, drawing-model, render callback и
адаптер Lightweight Charts. Формат данных, API controller и зависимости сохраняются.
