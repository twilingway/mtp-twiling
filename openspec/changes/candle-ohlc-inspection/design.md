## Context

На графике есть значения OHLC, подписка на перекрестие и адаптер преобразования координат. Связанное
перекрестие может обновляться из другого окна.

## Decisions

- Подсказка у свечи получает только локальные события указателя. Время, вычисленное адаптером для
  выбранного столбца, ищется среди реальных свечей этого графика.
- Для панели используются её точность цены и существующие цвета OHLC. Позицию подсказки ограничивают
  видимая область ценовой панели и размер самой карточки.
- Режим и задержка добавляются в необязательные поля настроек панели. Старые копии открываются с
  подсказкой у свечи без задержки.
