# Proposal

## Why

На телефоне оформление выбранного объекта требует большого контекстного меню. Нужна компактная
перемещаемая панель для частых действий без перекрытия графика.

## What Changes

- Выбор рисунка или изображения показывает плавающую панель на телефоне.
- Панель предоставляет поддерживаемые цвета, толщину, стиль, удаление и полное меню через
  многоточие.
- Перетаскивание за ручку ограничено видимой областью; остальные жесты графика сохраняются.

### Modified Capabilities

## Impact

ContextMenu и новые UI helpers/CSS; существующие controller API и формат данных сохраняются.
