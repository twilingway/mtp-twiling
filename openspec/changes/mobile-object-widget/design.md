# Design

## Context

ChartDialogs уже получает controller активного окна через TerminalContext. selectedObject хранит
выбор, contextMenu используется существующим полным меню. Новые глобальные поля не нужны.

## Goals / Non-Goals

Дать компактное редактирование всех девяти DrawingTool и действия изображения. Жесты выделения и
движения canvas реализуются отдельным изменением без изменения controller API.

## Decisions

- При узком viewport или coarse pointer выбранный объект показывает widget; contextMenu имеет
  приоритет и открывает существующее полное меню. Desktop сохраняет текущее поведение.
- Оформление меняется через updateDrawing, удаление через tools.deleteObject. Возможности
  определяются типом объекта: изображения не получают несуществующие цвета и линии.
- Ручка использует pointer capture; положение ограничивается visualViewport и пересчитывается при
  resize/scroll без таймеров. У панели нет полноэкранного слоя.
- Цвет уровней Фибоначчи включает существующий oneColor, чтобы выбранный цвет был видимым.

## Risks / Trade-offs

Нативные color/select имеют оформление браузера → сохраняются доступные touch targets и подписи.
Реальный вид и touch проверяет координатор на единой интегрированной версии.

## Migration Plan

Изменений данных нет. Откат удаляет UI и CSS без миграции.
