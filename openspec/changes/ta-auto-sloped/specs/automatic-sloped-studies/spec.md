# Spec Delta

## ADDED Requirements

### Requirement: Auto pitchfork uses confirmed alternating pivots

Автоматические вилы SHALL строиться по трём подтверждённым чередующимся экстремумам и выбранной
геометрии медианы.

#### Scenario: Last candle has not closed

- **WHEN** третья опора подтверждается только на открытой последней свече
- **THEN** индикатор сохраняет прежние подтверждённые вилы или остаётся пустым

#### Scenario: User changes fork geometry

- **WHEN** меняются тип вил, коэффициенты или направление продления
- **THEN** медиана и параллельные линии перестраиваются по тем же опорам с новыми параметрами

### Requirement: Trendlines use supported pivots and confirmed breakouts

Автоматические трендовые линии SHALL использовать подтверждённые пары вершин для сопротивления и
впадин для поддержки и учитывать заданное число последовательных закрытий.

#### Scenario: Closing prices break a line

- **WHEN** после подтверждения второй опоры подряд закрывается заданное число свечей за линией
- **THEN** продолжение заканчивается у свечи, которая подтвердила пробой

#### Scenario: Geometry is displayed across calendar gaps

- **WHEN** линия проходит через выходные или в будущую часть графика
- **THEN** её наклон соответствует логическим позициям свечей в обоих движках
- **AND** размеры сохраняются и после смены диапазона просмотра
