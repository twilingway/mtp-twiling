# Proposal

## Why

Названия стилей без образцов затрудняют выбор оформления, а стрелки меню разного размера теряются
рядом с инструментами.

## What Changes

- Список стилей и текущий выбор показывают сплошную, штриховую и точечную линии.
- Меню рисунков используют одинаковые SVG-стрелки; стрелка группы в левой панели получает отдельную
  видимую область нажатия.
- Клавиатура и закрытие списков сохраняют незавершённое редактирование окна.

### New Capabilities

### Modified Capabilities

- `drawing-editing`: наглядное и доступное управление оформлением рисунка.

## Impact

Компоненты drawing UI, отдельный CSS и проверки. Формат рисунков, математика, сохранение шаблонов и
семантика «ОК»/«Отмена» сохраняются. Подключение CSS и браузерная проверка выполняются при
интеграции.
