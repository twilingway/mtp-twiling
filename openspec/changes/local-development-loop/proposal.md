# Быстрый локальный цикл

## Why

Проверка небольших правок через полные тесты, релизную сборку и main задерживает работу на
компьютере и подключённом телефоне.

## What Changes

- Локальный сервер инкрементально пересобирает клиент и перезагружает страницу после изменения
  файлов.
- Разработка не запускает полный набор тестов и не меняет релизные артефакты.
- Один адрес доступен компьютеру и телефону через USB-перенаправление порта.

## Capabilities

### New Capabilities

- `local-development-loop` — изолированная локальная разработка с автоматическим обновлением.

### Modified Capabilities

## Impact

Команда разработки, общий конфиг браузерной сборки, локальный HTTP-сервер и документация.
