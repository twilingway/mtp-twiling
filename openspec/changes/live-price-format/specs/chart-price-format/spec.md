# Spec Delta

## Purpose

Обеспечить точное отображение цены после поступления метаданных инструмента без потери выбранного
пользователем участка графика.

## ADDED Requirements

### Requirement: Актуальный шаг цены

Оба графика SHALL применять конечный положительный шаг цены текущего инструмента к шкале и метке
последней цены, включая дробные шаги в научной записи. До получения корректного шага SHALL
использоваться временный формат.

#### Scenario: Поздние метаданные

- **WHEN** после создания графика VTBR приходит шаг 0.005 либо для TGKA приходит шаг 0.000002
- **THEN** цена отображается с точностью не менее трёх либо шести знаков соответственно

#### Scenario: Невалидный шаг

- **WHEN** приходит отсутствующий, нулевой, отрицательный либо бесконечный шаг
- **THEN** текущий формат не заменяется этим значением

### Requirement: Точность при неизвестном шаге

При неизвестном шаге график SHALL сохранять фактически полученную точность цены до девяти знаков.
Резервная точность SHALL только увеличиваться в пределах текущего графика, пока корректный шаг не
станет авторитетным. Полученная точность SHALL не объявляться минимальным биржевым тиком и не
изменять цену источника.

#### Scenario: Маленькая цена до метаданных

- **WHEN** до шага TGKA известна цена 0.004842
- **THEN** график отображает 0.004842 вместо 0.00 с первого создания

#### Scenario: Расширение без колебаний

- **WHEN** при неизвестном шаге поступают цены 1.09856, затем 1.1
- **THEN** точность текущего графика остаётся пять знаков

#### Scenario: Реальная цена источника

- **WHEN** indicative EUR/USD не имеет шага и API возвращает ровно 1.1
- **THEN** формат не подменяет цену значением другого источника и не выводит из неё договорный шаг

#### Scenario: Приоритет полученного шага

- **WHEN** после резервной точности девять знаков приходит шаг 0.000002
- **THEN** график применяет точность шага шесть знаков и следующие price hints не отменяют её

### Requirement: Сохранение камеры и источника

Обновление формата SHALL сохранять экземпляр графика, данные и пользовательскую камеру. Метаданные
SHALL применяться только к действующему графику текущих владельца, UID, сессии и источника; импорт и
восстановление SHALL блокировать применение.

#### Scenario: Изменение после масштабирования

- **WHEN** шаг уточняется после прокрутки и масштабирования графика
- **THEN** график не пересоздаётся, история не загружается повторно и камера не сбрасывается

#### Scenario: Метаданные во время создания

- **WHEN** шаг уточняется до завершения асинхронного создания графика
- **THEN** созданный график получает последнее корректное значение

#### Scenario: Устаревший источник

- **WHEN** обновление относится к другому UID, владельцу, сессии либо уже выведенному из
  использования графику
- **THEN** оно не изменяет формат действующего графика
