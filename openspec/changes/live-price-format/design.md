# Design

## Context

Формат задавался однократно при создании native series. Шаг цены не входит в ключ жизненного цикла
canvas; сведения каталога могут прийти после запуска асинхронной фабрики. Мотивация — в proposal.md.

## Goals / Non-Goals

**Goals:** изменить только формат существующей серии публичным API движков и сохранить границы
владения.

**Non-Goals:** изменение восстановления камеры после reload и управление шириной нативной оси.

## Decisions

- Необязательный метод адаптера принимает owner, UID и положительный шаг. Lightweight применяет
  priceFormat к серии, KLine — точность цены; повтор одного формата пропускается. Пересоздание по
  ключу шага отвергнуто из-за потери камеры и повторной загрузки.
- Подписка рядом с жизненным циклом canvas проверяет текущие owner, UID, session, revision и
  viewKey. Немедленный вызов после фабрики закрывает окно поздних метаданных; cleanup снимает
  подписку. Адаптер дополнительно отклоняет retired и чужие owner/UID.
- Общая чистая функция учитывает десятичную и научную запись шага с точностью 2–9. Неизвестный шаг
  хранится как null; фактическая цена расширяет резервную точность до nano-разрешения без
  последующего сужения. Настоящий положительный шаг отменяет резервную точность и сохраняет
  приоритет.
- Lightweight использует custom formatter при неизвестном шаге. Обязательный native minMove=1e-9
  задаёт лишь разрешение API-числа, а не вымышленный договорный тик; исходный row.step не меняется.
- Проверка API 25.11.2026: EUR/USD indicative/refinitiv, UID 980156e9-4f81-4ee2-af21-895b57a2b1bf,
  minPriceIncrement отсутствует; last и DAY close равны 1.1. Price hint доказывает только видимые
  знаки, не штатную точность FX и не цену TradingView. Доказательства:
  artifacts/tbank-fx-catalog-audit.json в canonical (read-only внешний QA-артефакт, не часть
  коммита).
- Изменение проходит через существующий programmatic camera guard и не вызывает setData, setView или
  fit; пользовательская линия последней цены остаётся той же.
- В установленном KLine 9.8.12 setPriceVolumePrecision меняет только store; последующий публичный
  setStyles с пустой дельтой запускает перерисовку нативных меток без смены оформления.

## Risks / Trade-offs

- Нативная ось может менять ширину при увеличении числа цифр → модельные тесты доказывают отсутствие
  команд камеры и смены данных; визуальную проверку реального движка выполняет отдельный QA после
  интеграции.
- Наблюдавшийся reload-сдвиг около трёх пикселей не накапливается и не переписывает сохранённую
  камеру; причинная связь с метаданными не доказана, изменение не включено.

## Migration Plan

Хранимый формат не меняется. Интеграция локальным коммитом; откат коммита возвращает прежний
временный формат без миграции данных.
