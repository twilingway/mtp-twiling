# Design

Точность вычисляется из биржевого шага. Шкала Lightweight Charts использует формат серии с
наименьшим порядком отрисовки, поэтому цены свечей и пересекающих ту же шкалу скользящих средних
получают общий формат. KLineChart применяет точность через публичный API.

При запуске данные каталога обновляют шаг сохранённой строки по UID. Если шаг CNYRUBF отсутствует в
сохранённых метаданных, используется значение из спецификации контракта Московской биржи.
[Спецификация CNYRUBF](https://www.moex.com/ru/derivatives/perpetual-futures/cnyrubf)
