# Verification

## Регрессия 0.3.50

В 0.3.49 (`0733fcaea2accafa`) воспроизведена потеря текста/заметки при явном выборе курсора до Save.
После Save объекты сохранялись. Базовая проверка всех десяти аннотаций и 24 остальных рисунков с
изображением подтвердила сохранение после выбора курсора, смены TF и reload в LW/KLine.

Исправление `2eda465eb086e533`: переход к курсору/другому инструменту подтверждает корректное
создание. 20 новых проверок выполняют реальные creation/editing/settings команды: один объект и
undo, пустой текст, Cancel, конкурирующие Save, новый draft во время записи, ошибки хранения, смена
контекста и импорт во время сохранения камеры. Независимый reviewer воспроизвёл два P2 и подтвердил
их устранение: новый draft и импортированные настройки не теряются.

Локальный `pnpm check`: 2773 pass, 0 fail, 4 optional skips. Strict OpenSpec: 138 pass. Артефакты
базового и исправленного браузерных прогонов сохраняются отдельно в ignored
`artifacts/annotation-cursor-repro-20261128/` и `artifacts/nonannotation-audit-20261128/` основного
workspace. DEV использует build `dev`; соответствующий source hash приведён выше. Физический телефон
не использовался; пользовательские Chrome, профиль и облачные данные не изменялись.

Исправленный DEV проверен через настоящий UI: 10 аннотаций и 24 рисунка с изображением в обоих SDK,
всего 70 сочетаний тип/движок. Шесть inline-аннотаций сохраняются по выбору курсора без Save; для
таблицы использован Ок → курсор, поскольку нативный modal не допускает внешний клик. Смена TF,
reload и сохранённые ID проверены. Cancel/Escape не добавляют объектов, undo/redo даёт 20 → 19 → 20.
Изображения, линии и фигуры сохраняются; отдельный повтор на свободном участке устранил перекрытие
координат теста загруженным изображением. Ошибок приложения не выявлено.

Финальные отчёты: `annotation-cursor-repro-20261128/fixed-manifest.json` и
`nonannotation-audit-20261128/fixed/manifest.json` внутри ignored `artifacts/`. PNG просмотрены
только в изолированных агентах; снимки фоновой вкладки с частичной отрисовкой не использованы как
единственное визуальное доказательство. Собственные браузерные сессии завершены.

собственных якорей, независимость clone, table bounds и транзакции Save/Cancel. Независимый reviewer
нашёл ошибки clone/caption/table и подтвердил их исправление.

Оба SDK и темы проверены в изолированном браузере. Начальные PriceLabel/PriceNote P2 устранены:
повторная проверка build `cab563ee11b26859` подтверждает native создание и редактирование на desktop
и mobile390. Физический телефон не использовался.
