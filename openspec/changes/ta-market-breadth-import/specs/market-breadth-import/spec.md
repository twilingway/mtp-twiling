# Spec Delta

## Purpose

Дать проверяемый локальный источник истории ширины выбранного рынка для дневного графика.

## ADDED Requirements

### Requirement: Явное покрытие выбранного рынка

Приложение SHALL принимать версию 1 локального JSON только с источником, описанием исторического
состава, единицей измерения объёма и однозначными состояниями всех календарных дней покрытия.

#### Scenario: Состав меняется в разные дни

- **WHEN** строки содержат корректные, но разные размеры совокупности рынка по датам
- **THEN** источник принимается и каждый торговый день вычисляется по своему составу

#### Scenario: День отсутствует либо повторён

- **WHEN** в пределах заявленного покрытия пропущена либо повторена дата
- **THEN** импорт отклоняется до расчёта

### Requirement: Данные связываются с датами дневного графика

Пользователь SHALL явно выбрать рынок для сравнения локальным файлом. Индикатор SHALL отображать
идентификатор выбранного рынка и сопоставлять его агрегаты со свечами дневного графика по точной
дате. Точка закрытого дня, отсутствующей даты или интервала помимо дневного SHALL отсутствовать.

#### Scenario: Котировка открылась по местному времени

- **WHEN** UTC-метка открытия приходится на предыдущий день, а в календаре рынка наступило первое
  число
- **THEN** точка использует только агрегат первого числа

#### Scenario: Для выбранного показателя нет данных

- **WHEN** дневные свечи не пересекаются с доступными датами выбранного показателя
- **THEN** приложение показывает отсутствие данных вместо подписи готового ряда

### Requirement: Пропуски различают закрытый рынок и необнаруженный агрегат

Закрытый день SHALL сохранять предыдущую накопленную сумму для следующего сеанса. Неизвестный
торговый день или агрегат SHALL делать соответствующую накопленную сумму неизвестной. A/D Ratio
SHALL делить счётчики конкретного известного дня с ненулевым знаменателем.

#### Scenario: Выходные и пропуск данных

- **WHEN** после опубликованной пятницы указан закрытый выходной, а понедельник опубликован
- **THEN** следующая накопленная точка учитывает пятницу и понедельник
- **AND** неизвестный вторник прерывает последующие накопленные точки, оставляя независимые
  отношения за известные дни
