# Design

Очередь ручного переноса сообщает об ожидании, чтении, проверке, сохранении и восстановлении.
Экспорт сообщает о сборе данных, формировании JSON и передаче браузеру. Окно вычисляет прошедшее
время по монотонным часам и показывает фактический размер выбранного файла или сформированного JSON.
Состав относится к файлу.

Состояние операции хранится в открытом окне. Сообщения очереди опциональны, поэтому программные
вызовы синхронизации продолжают использовать существующий интерфейс.
