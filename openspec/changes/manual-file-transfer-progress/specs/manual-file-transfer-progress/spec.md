## ADDED Requirements

### Requirement: Ручной перенос показывает этап и результат

Вкладка ручного переноса SHALL показывать текущий этап, прошедшее время и известный размер файла,
пока операция выполняется. По завершении вкладка SHALL показывать результат и длительность. Состав
файла SHALL быть виден после успешного чтения или подготовки.

#### Scenario: Долгое восстановление после записи

- **WHEN** пользователь импортирует допустимый JSON и восстановление рабочего пространства
  задерживается
- **THEN** вкладка показывает восстановление рабочего пространства и обновляет показанное время
- **AND** подтверждение появляется после завершения восстановления

#### Scenario: Передача выгрузки браузеру

- **WHEN** пользователь экспортирует рабочее пространство
- **THEN** вкладка показывает этап подготовки файла
- **AND** после передачи файла браузеру показывает его объём и состав

#### Scenario: Браузер вернул файл без доступа к содержимому

- **WHEN** чтение файла завершается ошибкой доступа
- **THEN** вкладка останавливает индикатор и предлагает выбрать скачанную копию
