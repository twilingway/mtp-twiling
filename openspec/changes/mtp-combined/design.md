# Design

## Context

См. proposal.md. Исходные Pine содержат три непересекающихся набора SMA от 4 до 640. Наши адаптеры
уже рисуют их общим canvas-слоем, поэтому лимита на три пункта нет.

## Goals / Non-Goals

**Goals:** единое управление точным объединением исходных линий и обратная совместимость профилей.

**Non-Goals:** добавление всех целочисленных периодов 1–640, Pine-интерпретатора или изменение
исходных формул.

## Decisions

- Новый необязательный флаг `mtpAll`, по умолчанию выключен: старые профили и backup остаются
  допустимы.
- Периоды объединяются без дубликатов. При активном объединённом варианте он владеет общим стилем, а
  отдельные группы не рисуются повторно.
- Список исходных периодов остаётся единственным источником данных; отдельный новый список из 640
  периодов изменил бы исходный индикатор.
- Включение единого варианта выключает старые группы; включение отдельной группы выключает единый.
  Скрытие единого варианта не включает группы самопроизвольно.

## Risks / Trade-offs

- Наложение стилей старых групп → общий стиль применяется только при активном едином варианте.
- Отсутствующий флаг в старом backup → трактуется как выключенный без миграции данных.
- Нагрузка всех линий → математика и renderer совпадают с уже поддерживаемым одновременным
  включением трёх групп; нужен visual smoke двух движков.

## Migration Plan

Добавить необязательное поле и проверку импорта. Старые сохранения не переписывать автоматически.
Публиковать после общего check и браузерной проверки.
