## Context

Чистые расчёты уже возвращают состояния Woodies CCI, опорные точки дивергенций и события разворотов
Букера. Общее представление использует ряды, привязанные к свечам.

## Goals / Non-Goals

Перенести рассчитанные ряды и события на график. Для Knoxville нужен подтверждённый алгоритм выбора
опорных точек. Для уровней Букера нужны подтверждённые календарные периоды и правила объединения
истории на разных интервалах.

## Decisions

- Четыре канала столбцов Woodies CCI делят между собой позиции медленного CCI. На каждом индексе
  только канал соответствующего состояния получает значение.
- Линии дивергенции используют отдельные ряды с разрывами для каждого типа. Видимые отрезки линейно
  соединяют только подтверждённые опорные точки. Скрытые дивергенции включаются через параметры.
- Настройки и направления разворота Букера соответствуют опубликованному условию, а числовые
  значения по умолчанию заданы в MTP. Бычья метка рисуется ниже минимума, медвежья выше максимума
  сигнальной свечи.
  [Справка Rob Booker Reversal](https://www.tradingview.com/support/solutions/43000599840-rob-booker-reversal/)
- Обычный график подтверждает закрытие свечи по появлению следующей свечи. Без такого подтверждения
  новую дивергенцию или разворот на правом краю не показываем.

## Risks / Trade-offs

История графика не хранит признак закрытия последней свечи. Если следующая свеча ещё не поступила,
например после окончания торгов, сигнал может отобразиться после открытия следующей сессии.
