## Context

Публичное описание связывает направление цены, противоположное направление Momentum и состояние
перекупленности или перепроданности RSI.
[Справка Knoxville](https://www.tradingview.com/support/solutions/43000591336-rob-booker-knoxville-divergence/)

## Decisions

- Вариант MTP использует соседние подтверждённые максимумы High или минимумы Low. Каждая опора
  должна строго превосходить соседей по своему направлению. Опора подтверждается, когда закрыто
  заданное количество свечей справа.
- Momentum цены закрытия равен разнице между текущим закрытием и закрытием на выбранный период
  раньше. RSI рассчитывается по закрытиям. Порог RSI проверяется в момент второй опоры.
- Каждая новая опора того же типа становится предыдущей для следующего сравнения. Сравнение
  выполняется, когда расстояние между опорами не превышает установленного числа свечей. Пропуск
  любого поля OHLC начинает новый непрерывный участок с отдельным прогревом.
- По умолчанию Momentum берётся за 20 свечей, RSI за 14, радиус экстремума равен 2, расстояние
  ограничено 50 свечами, пороги RSI равны 30 и 70. Выбор последовательных экстремумов, момент
  проверки RSI и эти значения относятся к реализации MTP.
- Линия заканчивается в точке второй опоры. Дополнительная свеча используется только для
  подтверждения, когда факт закрытия последней свечи неизвестен.
