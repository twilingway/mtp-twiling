# Proposal

## Why

После основного закрытия API возвращает сегодняшнюю цену сессии, поэтому VTBR показывает минус
вместо дневного роста. Нужна база предыдущего дня относительно последней сделки.

## What Changes

- Проверять даты и цены базы; использовать предыдущее вечернее закрытие или завершённую биржевую
  дневную свечу.
- Разделять неизвестное изменение и нулевое; обновлять базу при смене даты сделки без запросов на
  каждом тике.
- Точно подписывать базу ТБанка для фьючерсов.

## Capabilities

### New Capabilities

- `daily-quote-change`: достоверное дневное изменение от предыдущего закрытия ТБанка.

### Modified Capabilities

Нет.

## Impact

Котировки, watchlist, добавление инструмента, локальный snapshot, переводы и unit tests. Новые
зависимости и публикация не нужны.
