# Design

## Context

Оба движка используют общую отрисовку разметки. В сохранённых рисунках есть текст и привязка по двум
осям. Цвет подписи раньше совпадал с цветом контура.

## Goals

- Сохранить старые подписи и геометрию.
- Разместить текст возле выбранного края видимой фигуры или в центре.
- Использовать одни настройки в предварительном просмотре, шаблонах, буфере, JSON и Google Диске.

## Decisions

- Опциональное поле `textColor` принимает шестизначный HEX. При отсутствии поля цвет следует за
  контуром. Это поведение доступно и при сбросе цвета в палитре.
- Для общей подписи диапазон выбора составляет 1–72 px. Ранее сохранённый допустимый размер до 100
  px сохраняется до смены размера.
- Линии используют прежнюю видимую часть отрезка. Прямоугольники и общая подпись Фибоначчи
  используют видимую часть области и одни правила размещения. Числа и комментарии отдельных уровней
  Фибоначчи сохраняют цвет соответствующего уровня.
- Обновлённый клиент сохраняет поле при синхронизации. Уже выпущенный клиент распознаёт неизвестное
  поле при чтении и сохраняет удалённую копию для открытия после обновления.
