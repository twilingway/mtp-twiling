# Proposal

## Why

В раскладке сравнения дополнительные графики показывают только свечи. На телефоне панели браузера
занимают часть высоты графика.

## What Changes

- Добавить раскладки от одного до шестнадцати графиков с явным выделением панели для редактирования.
- Разрешить рисование и добавление индикаторов во всех панелях.
- Добавить кнопку входа в полноэкранный режим и выхода из него.

## Capabilities

### New Capabilities

- `interactive-chart-grid` предоставляет инструменты редактирования и отображения в каждой панели.

## Impact

Рабочая область, панель инструментов, локальные настройки и существующие источники свечей.
