# Design

Основной профиль сохраняет текущий интерфейс входа, резервное копирование и один рыночный клиент.
Каждая дополнительная панель использует собственный контекст графика с тем же клиентом. Её
инструмент и индикаторы сохраняются локально по профилю и номеру панели. Выделение панели
перенаправляет общие инструменты и клавиатурные команды. Настройки основного графика сохраняются с
прежним форматом.

Панели одного инструмента используют существующий локальный документ разметки. Обновления передаются
открытым панелям в порядке сохранения. Запросы свечей имеют отдельные подписки и прекращаются при
закрытии панели, смене источника или импорте. Набор живых рыночных источников остаётся прежним.

Полноэкранный запрос выполняется из действия пользователя. Состояние синхронизируется с событиями
браузера. При отказе доступен расширенный режим внутри страницы.

Глубина истории использует единый компактный заголовок ценовой панели при любом числе графиков.
Выбор остаётся привязан к контроллеру панели; нижняя строка не создаётся. В узких заголовках
сокращаются название инструмента и единица измерения, но число дней сохраняется. Высота заголовка
ограничена измеренной ценовой панелью и восстанавливается после выхода из фокуса индикатора. Часовой
пояс доступен отдельно в общем меню аккаунта.
