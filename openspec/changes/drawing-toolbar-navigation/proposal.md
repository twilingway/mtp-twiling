# Proposal

## Why

Левая панель использует условные символы и сокращённый набор меню, поэтому пользователь не может
применять привычные действия TradingView. Нужны узнаваемые пиктограммы, правильная группировка и
работающие настройки рисования.

## What Changes

- Семь групп инструментов и палитра знаков в подтверждённом порядке, SVG-пиктограммы собственной
  реализации, последнее выбранное средство группы, отдельная стрелка раскрытия.
- Заголовки секций внутри общего popup, избранное, клавиатурная навигация и закрытие по Escape или
  клику вне меню; доступные действия имеют реальные обработчики.
- Перекрестие/точка/стрелка/ластик, измерение и выбор области увеличения.
- Слабый/сильный магнит, режим непрерывного рисования, отдельные меню блокировки и скрытия, удаление
  рисунков/индикаторов/всего с учётом зафиксированных объектов.
- Сохранение настроек по пользователю, перенос через backup; оба движка используют общую модель.
- Полный список инструментов переносится по семействам вместе с геометрией и настройками; запись в
  реестре сама по себе не считается реализованным инструментом.

## Capabilities

### New Capabilities

- `drawing-toolbar`: выбор, группировка и общие режимы инструментов рисования.

### Modified Capabilities

Нет: существующая `drawing-editing` остаётся владельцем clipboard и undo.

## Impact

DrawingToolbar, общие настройки профиля, ChartGestures, renderer/hit-test и chart adapters. Новых
зависимостей, доступа к аккаунтам и серверных API не требуется. Исходные SVG/код TradingView не
включаются в приложение; используется отдельно подтверждённое поведение.
