# Design

## Context

DrawingToolbar сейчас содержит восемь средств общей модели и две короткие выпадашки. Оба движка
передают рисование в общий canvas renderer. Проверенный реестр групп и служебных меню находится в
`vps/artifacts/toolbar-reference`; геометрия большинства средств ещё не перенесена.

## Goals / Non-Goals

**Goals:** единая типизированная структура меню, независимые SVG, корректные состояния split-button,
сохранение режимов и реальные эффекты общих действий в обоих движках.

**Non-Goals:** брокерские позиции/торговые операции, публикации и социальные функции. Другие
пользовательские задачи сохраняются в очереди; эта спецификация не закрывает их.

## Decisions

- Отделить статический реестр названий/групп/секций от availability и обработчиков. Для каждого
  средства capability соответствует реальной геометрии и lifecycle; неподдерживаемая запись остаётся
  явно недоступной до реализации, не вызывает другой инструмент под тем же названием.
- Собственные SVG в viewBox28, currentColor, одинаковые размеры; без Unicode-псевдоиконок и переноса
  чужих исходных SVG. Последний инструмент группы определяет главную кнопку, стрелка отдельно
  открывает меню. Секции — один popup, служебные режимы — отдельные меню.
- Режимы входят в настройки профиля/backup. Временные popup/focus принадлежат React, а не
  сохранению. Глобальная видимость и блокировка не переписывают индивидуальный visible/lock каждого
  объекта.
- Магнит вычисляет ближайшую разрешённую точку свечи в пикселях через общий projector; слабый
  применяет порог, сильный выбирает всегда. Привязка к индикаторам добавляется вместе с доступом к
  рассчитанным сериям, без подмены их точками свечи.
- Блокировка предотвращает перемещение, не запрещает открывать настройки/выбирать в дереве. Удаление
  зафиксированного требует явной сохранённой политики или подтверждения.

## Risks / Trade-offs

- [Длинные меню не помещаются] → ограничение viewport, прокрутка, keyboard scrollIntoView; на узком
  экране drawer, без обрезания строк/кнопок.
- [Новый режим повреждает существующий рисунок] → общая undo-операция, Escape/pointercancel,
  регрессии locked/hidden/incomplete gesture и актуального owner/instrument.
- [Внешнее сходство опережает поведение] → отдельно отслеживать registry/UI/geometry/settings/QA
  каждого семейства; не отмечать семейство готовым по наличию иконки.

## Migration Plan

Новые поля настроек необязательны и имеют безопасные defaults. Старые backups остаются валидными.
Новые средства добавляются в валидацию/clipboard до открытия их выбора пользователю.
