## Why

В личном терминале нужны криптопары, которых нет у Bybit. OKX расширяет выбор спотовых пар и
бессрочных USDT-контрактов при подтверждённом отсутствии точного рынка у основного источника.

## What Changes

- Поиск показывает проверенные пары OKX с явным названием биржи.
- Сохранённая пара OKX получает цену, историю и поток с этой биржи. Рабочее пространство хранит её
  собственный идентификатор.
- Запросы к публичному API выполняются напрямую с устройства для личного просмотра.

## Capabilities

### Modified Capabilities

- `public-market-terminal` добавляет второй публичный источник и правила его выбора.
- `provider-portable-profiles` закрепляет перенос и совместимость идентификаторов OKX.

## Impact

Поиск инструментов, отображение источника, данные рынка, локальный кеш, перенос профиля, сетевой
список разрешений PWA.
