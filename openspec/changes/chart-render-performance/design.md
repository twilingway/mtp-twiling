# Измерения и границы

## Context

На SIBN 1Д с MTP профиль браузера показал существенное время перевода цен в экранные координаты.
Общие компоненты подписываются на полный снимок состояния и получают обновления каждой котировки.

## Decisions

- Сохранять расчёт средних, периоды, ценовые экстремумы и фактическую геометрию линий.
- Переиспользовать результат перевода одной координаты X внутри одного кадра.
- Применять линейный перевод Y только при известном линейном режиме ценовой шкалы.
- Подписки интерфейса сравнивают используемые поля и сохраняют актуальные цены.
- Календарная ось хранит локальные части даты для загруженных свечей по позиции и timestamp.
  Повторные проходы не вытесняют весь кеш длинной внутридневной истории.

## Risks / Trade-offs

- Нелинейная шкала требует исходного преобразования движка.
- Узкие подписки могут пропустить изменение настройки. Проверки охватывают котировки и переключение
  активного инструмента.
- Эмуляция телефона характеризует нагрузку на сцену. Фактическая плавность требует замера
  подключённого устройства.
