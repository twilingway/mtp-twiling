## Purpose

Инструменты, рисунки и настройки сохраняются при любом порядке подключения рынка и облака.

## ADDED Requirements

### Requirement: Независимость от авторизации рынка

Рабочее пространство SHALL сохранять идентичность при API connect/disconnect/relogin и смене ключа.
Изменение market auth SHALL NOT очищать инструменты, рисунки, индикаторы, камеры или раскладку.

#### Scenario: Сначала Google, затем API

- **WHEN** пользователь настраивает инструменты, подключает Google и затем API Т-Банка
- **THEN** рабочее пространство сохраняется, а Google остаётся независимым подключением

#### Scenario: Выход из API

- **WHEN** пользователь отключает API после настройки графиков
- **THEN** настройки и кешированные реальные данные остаются, а Google credential не удаляется

### Requirement: Перенос без потери источников

Миграция SHALL сохранять legacy источники, текущие значения и конфликтующие альтернативы. Отмена или
ошибка SHALL NOT выдавать пустой профиль как готовый. Повторный запуск SHALL продолжать журнал.

#### Scenario: Существуют разные старые профили

- **WHEN** public и прошлый hash-owner содержат разные данные
- **THEN** текущий готовый workspace имеет приоритет, а остальные данные сохраняются для recovery

#### Scenario: Сбой записи

- **WHEN** миграция прерывается до готовности
- **THEN** источники сохранены, старое видимое состояние либо явный retry остаются доступны
