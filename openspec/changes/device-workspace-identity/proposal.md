# Единое рабочее пространство устройства

## Why

Подключение API меняет owner с public на hash(token). Существующее копирование переносит не все
настройки и прекращается при наличии target-данных; инструменты выглядят сброшенными. Выход из API
также удаляет Google credential, связывая независимые подключения.

## What Changes

- Каноническое локальное пространство device не зависит от ключа API или порядка подключения.
- Существующие данные переносятся COW с журналом и сохранением исходников и конфликтов.
- Google использует выбранный legacy alias без переименования зашифрованного credential.
- Сбой переноса сохраняет видимое состояние либо явное восстановление, а не пустой готовый профиль.
