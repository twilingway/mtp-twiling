# Design

## Context

Настройки графика уже сохраняются для владельца и проходят проверку при импорте. Оба адаптера
пересоздаются при изменении настроек с сохранением камеры. Оболочка содержит жёсткие тёмные цвета в
нескольких CSS-файлах.

## Goals / Non-Goals

**Goals:** единая чистая модель палитры, необязательное поле темы для старых профилей, существующий
путь сохранения и восстановления вида графика.

**Non-Goals:** системная автоматическая тема, изменение изображений и палитр пользователя, новые
хранилища, зависимости или версия резервной копии.

## Decisions

- `ChartSettings.theme` принимает `dark` или `light`; отсутствие означает `dark`. Отдельная
  настройка устройства отвергнута, поскольку выбор должен переноситься с профилем.
- Чистая модель темы разрешает фон и палитру canvas. Смена темы заменяет только отсутствующий фон
  либо точное совпадение с фоном предыдущей темы, включая старый стандартный тёмный фон. Собственные
  цвета не преобразуются.
- React-эффект устанавливает `html[data-theme]`, `color-scheme` и `meta[name=theme-color]`; CSS
  меняет только элементы оболочки. Инверсия и фильтры не применяются.
- Адаптеры используют палитру для сетки, текста, границ и перекрестия, сохраняя существующие
  настройки свечей и линий. Существующее пересоздание адаптера восстанавливает камеру.
- Новый CSS подключается последним после завершения параллельной проверки текущего стенда; до этого
  существующие served-артефакты не меняются.

## Risks / Trade-offs

- [Неполный CSS-override] → отдельная визуальная проверка обеих тем и движков, включая меню и
  диалоги.
- [Собственный фон уменьшает контраст шкал] → дополнительно выбирать контрастную палитру canvas по
  яркости пользовательского фона.
- [Нельзя отличить намеренно выбранный стандартный цвет] → считать точное совпадение со стандартным
  фоном стандартным; остальные значения сохранять.

## Migration Plan

Добавить необязательное поле и CSS без изменения схемы backup. Проверить чистую модель, импорт и
типы, затем подключить CSS и выполнить браузерную проверку обоих движков. Откат кода безопасен:
новое поле необязательно, остальные данные неизменны.
