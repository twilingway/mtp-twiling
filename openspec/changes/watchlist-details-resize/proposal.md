# Proposal

## Why

Карточка инструмента занимает автоматически выбранную высоту. Пользователю нужно самостоятельно
распределять место между котировками и полной статистикой.

## What Changes

- Горизонтальный серый разделитель изменяет высоту всей нижней карточки мышью, касанием и
  клавиатурой.
- Список и карточка прокручиваются независимо; раскрытие статистики не меняет выбранную высоту.
- Доля высоты сохраняется в настройках владельца и переносится существующими резервными копиями.

## Capabilities

### New Capabilities

- `watchlist-details-layout`: управляемое распределение высоты списка и карточки инструмента.

### Modified Capabilities

Нет.

## Impact

Watchlist, новый разделитель и CSS, optional поле настроек и существующие allowlist резервных копий.
API котировок и версии схемы не меняются.
