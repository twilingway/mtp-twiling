## Why

Пользователь хочет открывать MTP во вкладке и по желанию устанавливать приложение. Для подключения
Т‑Банка в Chrome на Android нужна доступная инструкция по сертификату.

## What Changes

- Показываем кнопку установки по приглашению браузера и публикуем манифест.
- Открываем инструкцию по сертификату из настроек и рядом с кнопкой установки на узком экране.
- Сохраняем штатное обновление сайта и локальные сохранения.
- При доступной сети отдаём свежий манифест установки, при сбое используем его копию из кеша текущей
  оболочки: старый cache-first скрывал новые ссылки на PNG-значки.

## Capabilities

### New Capabilities

- `browser-only-terminal` описывает запуск, установку и обновление терминала.

## Impact

HTML-оболочка, шапка терминала, обработчики браузерных событий, шаблон service worker и подсказки
при первом запуске. Адрес манифеста, id, start_url и scope сохраняются.
