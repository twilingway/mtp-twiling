# Design

## Context

Типы уже сохраняются в chartSettings, проходят общий guard резервных копий и сохраняют камеру при
смене адаптера. Прямая подписка адаптера на бары отделена от React.

## Goals / Non-Goals

**Goals:** сохранить реальные OHLC, существующие настройки и независимые правила заливки/цвета.

**Non-Goals:** новые источники котировок, торговля, изменения инструментов рисования.

## Decisions

- Правила четырёх сочетаний взяты из
  [официального TradingView](https://www.tradingview.com/support/solutions/43000745270-hollow-candle-charts-explained/).
  Источник не задаёт равенство и первую свечу: нейтральный цвет и заполненный doji — явно выбранное
  детерминированное поведение проекта.
- Чистая модель определяет стиль без изменения OHLC. Используются существующие пользовательские
  цвета тела/границы/фитиля; автоматическая коррекция контраста сохраняет оттенок при необходимости.
- Lightweight получает нативные OHLC с индивидуальными color/borderColor/wickColor. Прозрачное тело
  действительно пустое: фон и сетка остаются видны, фитиль проходит только вне тела. Кэш ссылок на
  свечи обеспечивает O(1) для последней/новой свечи; историческая коррекция обновляет следующую
  свечу.
- KLine 9.8.12 выбирает все цвета только по open/close и не имеет per-bar style hook. Узкий
  зарегистрированный canvas renderer рисует свечи через публичный indicator draw API, а прозрачная
  исходная свечная серия сохраняет autoscale и OHLC. Renderer читает нативные текущие данные и
  видимый диапазон; не создаёт React state или отдельный redraw loop.

## Risks / Trade-offs

- Своя геометрия KLine → unit-проверка координат/штрихов и обязательная визуальная проверка
  координатором.
- Нейтральная первая свеча меняет цвет после подгрузки предыдущей истории → полная установка истории
  последовательно пересчитывает зависимость.

## Migration Plan

Расширить существующий allowlist без смены версии сохранений. Отсутствующий тип остаётся `candles`.
Новые копии требуют версии приложения с поддержкой `hollowCandles`.
