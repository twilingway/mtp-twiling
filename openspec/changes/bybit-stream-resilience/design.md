# Design

## Context

См. proposal.md. Действующий код уже сбрасывает retry на quote/candles и повторно подписывается.
PublicMarket вызывает catch-up после повторного open. Эти контракты сохраняются. Официальная
проверка 2026-11-28: https://bybit-exchange.github.io/docs/v5/ws/connect: ping каждые 20 секунд,
варианты pong и subscription ACK поддерживаются; до 500 соединений за 5 минут.

## Goals / Non-Goals

**Goals:** восстановить остановленный или зависший поток по сигналам браузера; сохранить причину.
**Non-Goals:** установить сетевого виновника без наблюдения реального сбоя; менять OHLC или
провайдера.

## Decisions

- Инъецируемый источник online/visible позволяет проверять восстановление без пользовательского
  Chrome.
- Сеть offline приостанавливает соединение без таймерного polling. Сигнал online возобновляет
  работу.
- После exhausted новый бюджет разрешён только по сигналу браузера, не чаще раза за 30 секунд.
  Свежий открытый сокет и ожидающий backoff не пересоздаются.
- Кольцо из 64 записей на владельца читается копией через getter; очищается при dispose. Ошибка
  WebSocket ожидает close короткое ограниченное время, чтобы сохранить code/wasClean.
- Причины ошибок фиксируются перечислением; произвольные server reason/frame не сохраняются.
- До callbacks владельца резервируются retry/exhausted и создание соединения. Каждая отмена и новое
  соединение меняют поколение; устаревшие продолжения не создают таймеры, а поздний результат
  фабрики закрывается. Это сохраняет одного владельца при синхронном обновлении подписок из notice.

## Risks / Trade-offs

- Браузер не раскрывает сетевую причину 1006 → диагностика не приписывает её бирже или провайдеру.
- Сон вкладки задерживает heartbeat → при возвращении устаревшее соединение переподключается.
- Повторный open предшествует первому quote → сообщение о восстановлении ждёт реальных данных.
