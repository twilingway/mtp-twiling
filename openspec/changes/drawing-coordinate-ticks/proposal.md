# Proposal

## Why

Поле цены рисунка показывает дробную координату даже для инструмента с целым шагом цены.

## What Changes

- Показать координату и шаг числового поля по данным выбранного инструмента.
- Привести явно изменённую цену к ближайшему допустимому шагу.
- Сохранить исходную координату при редактировании других параметров рисунка.

## Capabilities

### Modified Capabilities

- `drawing-editing` задаёт точность цены в диалоге координат.

## Impact

Поле координат рисунка, общие функции шага цены и тесты редактирования.
