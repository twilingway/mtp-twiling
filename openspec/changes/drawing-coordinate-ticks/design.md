# Design

Поле берёт шаг из метаданных выбранного по UID инструмента. Показанное значение округляется до
ближайшего шага, исходное значение остаётся в черновике. Ввод сразу обновляет черновик и
предпросмотр, а промежуточные символы сохраняются в поле до потери фокуса.

При отсутствии биржевого шага поле принимает цену с произвольной точностью.
