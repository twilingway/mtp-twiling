# Design

Сворачивание сохраняется отдельным необязательным флагом профиля вместе с последней вкладкой.
Повторные переключения сериализованы, не изменяют выбранный инструмент и не пересоздают canvas. На
desktop остаётся вертикальный rail, на mobile — короткая строка кнопок; ширина открытой панели
сохраняется отдельно. Контекстная команда открытия дерева не переключает его в закрытое состояние.

На mobile график занимает всю высоту над нижней навигацией. Список и дерево открываются поверх
графика на всю доступную площадь; canvas остаётся смонтированным с прежней геометрией. При новой
загрузке mobile-панель закрыта независимо от сохранённого desktop-раздела. Выбор бумаги возвращает
график. Временный mobile-флаг не входит в backup, desktop-настройки ширины не меняются.

## Context

Клиент банка уже умеет отписывать UID, но UI не вызывает удаление. Пустой сохранённый список
ошибочно заменяется заводским. Список и дерево теперь находятся в общей правой панели.

## Goals / Non-Goals

**Goals:** удалить строго одну запись и сохранить пустой список; общий разделитель правой панели.

**Non-Goals:** удаление истории/разметки вместе с записью; изменение торговых позиций пользователя.

## Decisions

- Идентичность для удаления: UID при наличии, иначе symbol недоступной записи. Отписка после
  сохранения; ошибки хранения возвращают предыдущее состояние списка.
- При отсутствии watchlist применяются начальные бумаги; пустой массив считается выбранным
  пользователем списком. Запросы и подписки с пустым набором UID не отправляются.
- sidebarWidth хранится в preferences. Во время жеста меняется только локальный размер/CSS,
  сохранение выполняется при отпускании; Escape/pointercancel откатывают жест.
- Минимум/максимум и доступное место под график ограничивают ширину. На узком экране панель
  открывается поверх графика, разделитель скрывается.
- Строки используют native desktop drag-and-drop; половина целевой строки определяет вставку
  до/после. Позиции относятся к полному списку, поэтому фильтр не теряет скрытые строки.
- Ручной порядок — порядок массива watchlist без отдельного ключа хранения. Перестановка проходит
  через общую очередь изменений и атомарно сохраняет watchlist/market до публикации состояния.
  Подписки, выбранная бумага, история и камера графика не меняются.
- Исходный owner, глобальные индексы и UID/symbol защищают от смены профиля и устаревших строк.
  Дубли импортированных UID адресуются индексом без удаления/объединения записей. Сортировка
  выключается только после подтверждённого сохранения, включая перенос к уже соседней строке.
- Выбор хранит optional instrumentUid: старые настройки без поля используют symbol, явный null
  адресует недоступную запись, строка — точный UID+symbol без перехода к другой бумаге. До переноса
  старый выбор закрепляется и сохраняется; история, подписка свечей, адаптер и countdown используют
  одну выбранную запись. Смена UID отменяет прежний запрос и незавершённый жест.

## Risks / Trade-offs

- Смена профиля во время операции → сохранённый owner/client и проверка актуальности перед UI.
- Изменение viewport → ограничить фактическую ширину без потери исходного предпочтения.
- Это ограниченное исправление стабильности выбора при перестановке. Namespace рисунков, изображений
  и видов остаётся по symbol; полная изоляция одинаковых тикеров требует отдельной canonical
  identity migration и этим изменением не заявляется. Точные дубли UID+symbol неразличимы как выбор
  инструмента.
