## Context

Синхронизация несколько раз запрашивает каталог снимков. Каждая проверка совместимости и запись
сверяют наблюдаемую версию облачных данных.

## Decisions

- На ожидание заголовков и на паузу без данных при чтении выделяется по 20 секунд. Долгое чтение с
  прогрессом продолжается. Тайм-аут завершает текущую попытку и сохраняет авторизацию для повтора.
- Каталог перечитывается перед каждой сверкой. Кеш хранит только подтверждённые манифесты текущего
  подключения. Повторное использование требует совпадения идентификатора, серверной версии файла,
  размера, ключа снимка и SHA‑256. При отсутствии версии читается тело.
  [Ресурс files Google Drive](https://developers.google.com/workspace/drive/api/reference/rest/v3/files)
- Параллельное чтение ограничено. Проверки содержимого новых манифестов, актуальных JSON и графа
  версий применяются перед обновлением отметки синхронизации и записью.
