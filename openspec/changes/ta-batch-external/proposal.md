# Proposal

## Why

Индикаторам ширины рынка, корреляции, открытого интереса и целей аналитиков нужны самостоятельные
источники. Технический рейтинг объединяет 26 индикаторов. Оба графика должны получать одинаковые
результаты с явными пропусками.

## What Changes

- Добавить чистые расчёты ширины рынка, отношения свечей и корреляции.
- Подготовить независимый ряд открытого интереса и уровни прогноза по данным поставщика.
- Добавить вычисление технических оценок по входным значениям составляющих.

## Capabilities

### New Capabilities

- `external-technical-indicators` — вычисления по свечам, независимым рыночным рядам и прогнозам с
  явными пропусками.

### Modified Capabilities

## Impact

Чистая модель и тесты. Запросы, реестр и отображение подключаются при интеграции.
