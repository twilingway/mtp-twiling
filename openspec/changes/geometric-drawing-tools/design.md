# Design

## Context

Оба адаптера уже используют общий canvas и hit-test. Расширяем эту границу, не добавляя нативные SDK
overlays.

## Goals / Non-Goals

**Goals:** единая проверяемая геометрия, доступные жесты, обратимость и совместимые резервные копии.

**Non-Goals:** новые торговые функции, серверное хранение ключей, заимствование исходников
TradingView.

## Decisions

- Типы и число якорей задаются общей политикой инструментов. Новые значения добавляются к прежнему
  формату без миграции старых рисунков.
- Чистая экранная геометрия возвращает пути, сегменты и рамки текста. Canvas и hit-test используют
  одни и те же точки; кривые дискретизируются с ограниченным числом сегментов.
- Окружность остаётся кругом в пикселях; дуга проходит через три якоря с линейным fallback при
  коллинеарности. Rotated rectangle использует проекцию третьего якоря на нормаль базового ребра.
- Ломаная замыкается повтором первого якоря. Свободный штрих ограничен 2048 точками, интервалом 2px
  и прореживанием с сохранением концов.
- Общий input управляет захватом указателя; мышь сохраняет многокликовое создание, touch для двух
  точек сохраняет drag.
- Стрелка-указатель — широкий полигон; обычная стрелка — линия с открытым наконечником; up/down —
  однопозиционные символы.

## Risks / Trade-offs

- При сильном увеличении сегментация кривой требует достаточно мелких шагов; ограничиваем ошибку
  через зависимость числа шагов от экранной длины.
- Очень длинные штрихи прореживаются; первый и последний якоря обязательны.
- Browser smoke выполняет интегратор после общей сборки, включая оба движка и touch.
