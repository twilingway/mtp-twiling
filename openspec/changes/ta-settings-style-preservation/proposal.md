# Proposal

## Why

Сохранение одного периода сейчас превращает автоматические стили всех выходов в явные цвета.
Пользовательская правка параметров должна сохранять прежнее различие между отсутствующим и ручным
стилем.

## What Changes

- Период и размещение сохраняются без добавления отсутствующих стилей или полей старого стиля.
- Только выход, оформление которого пользователь изменил, получает полный явный стиль.
- Actual form submit проверяет сохранение структуры и прежние границы профиля/импорта.

## Capabilities

### New Capabilities

- `technical-indicator-style-intent`: сохранение автоматического и явно заданного оформления при
  редактировании настроек.

### Modified Capabilities

Нет: связанное описание панелей пока находится в незавершённом change, а не в основном каталоге
specs.

## Impact

Только настройки ТА, focused tests и документация. Формат instance/schema1, renderer, палитры и
native API сохраняются.
