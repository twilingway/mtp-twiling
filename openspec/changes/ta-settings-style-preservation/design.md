# Design

## Context

См. proposal.md. Форма использует полные defaults для показа элементов и затем сохраняет их все.
Legacy OutputStyle может не содержать opacity/lineStyle, а map styles может отсутствовать целиком.

## Goals / Non-Goals

**Goals:** сохранить исходную структуру untouched styles и материализовать только изменённый выход.

**Non-Goals:** новый reset/auto control, миграция схемы, renderer, палитры, сборка и публикация.

## Decisions

Draft хранит исходную sparse map либо undefined. Значения по умолчанию вычисляются отдельно для UI.
Style onChange объединяет defaults, прежний стиль этого выхода и конкретную правку; соседние записи
остаются прежними. Submit добавляет styles только при существующей map. Исходный spread instance
сохраняет даже наличие собственного undefined-поля, если оно было во входе.

Рассматривался dirty set поверх полной map, но отдельное разделение display defaults и persisted
draft не требует дополнительного состояния и исключает случайное сохранение untouched defaults.

## Risks / Trade-offs

- Правка с возвратом исходного значения остаётся явной → это разрешённое действие пользователя;
  сравнение цвета с default не определяет автоматический стиль.
- Отложенное сохранение после смены профиля/импорта → существующие current/queue guards сохраняются
  и проверяются actual form submit тестами.
