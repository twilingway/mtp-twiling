## ADDED Requirements

### Requirement: Приветствие с источниками данных

Приложение SHALL показывать короткое RU/EN приветствие с личной Drive-синхронизацией, публичным
GitHub и ссылкой privacy. Для гостя оно SHALL показывать подключение личного API Т‑Банка и
официальную ссылку получения токена. Текст MUST различать сервер оболочки и обновлений, IndexedDB
устройства и выбранные данные на личном Drive.

#### Scenario: Первый запуск до банковского входа

- **WHEN** начальное восстановление профиля завершилось, приложение готово в гостевом режиме,
  приветствие разрешено и другое окно закрыто
- **THEN** приветствие открывается без обязательного банковского или Google входа

#### Scenario: Восстановление сохранённого профиля Т‑Банка

- **WHEN** гостевой интерфейс уже готов, а приложение ещё восстанавливает сохранённый профиль
- **THEN** приветствие остаётся закрытым во время восстановления
- **AND** после успешного подключения Т‑Банка приветствие автоматически не открывается

#### Scenario: Ручное открытие помощи с подключённым Т‑Банком

- **WHEN** пользователь открывает помощь с подключённым Т‑Банком
- **THEN** помощь показывает статус подключения, сведения о Drive и данных, кнопку «Продолжить»
- **AND** в помощи отсутствуют приглашение подключить Т‑Банк и инструкция по получению токена

### Requirement: Устройственное скрытие и помощь

Чекбокс «Больше не показывать» SHALL сохраняться в IndexedDB устройства вне профиля банка и portable
backup. Приветствие SHALL оставаться доступным из настроек/помощи.

#### Scenario: Перезапуск и другой банковский профиль

- **WHEN** скрытие сохранено и приложение открывается с другим банковским профилем
- **THEN** автоматического приветствия нет, но ручное открытие доступно

#### Scenario: Ошибка записи IndexedDB

- **WHEN** браузер не разрешает сохранить скрытие
- **THEN** показана ошибка с повтором или продолжением без сохранения, без заявления об успешном
  скрытии
