## ADDED Requirements

### Requirement: Относительные осцилляторы на графике

Терминал SHALL добавлять Stochastic RSI, Coppock Curve, Relative Vigor Index, Relative Volatility
Index и Bull Bear Power из каталога в отдельную панель активного графика.

#### Scenario: Расчёт и переключение движка

- **WHEN** пользователь добавляет индикатор и на графике достаточно свечей для его параметров
- **THEN** терминал показывает рассчитанные значения и сохраняет их при переключении движка

#### Scenario: Недостаточная история

- **WHEN** пользователь открывает историю, где свечей меньше необходимого для расчёта
- **THEN** терминал оставляет значения без точки до окончания прогрева

### Requirement: Настройка и перенос осцилляторов

Терминал SHALL сохранять допустимые параметры и стили осцилляторов вместе с настройками графика.

#### Scenario: Перенос параметров

- **WHEN** пользователь меняет допустимый параметр индикатора и переносит настройки в другой профиль
- **THEN** новый профиль показывает тот же индикатор с сохранённым значением параметра
