# Proposal

## Why

Основная кнопка «Индикаторы» должна открывать поиск и библиотеку доступных индикаторов. Короткое
меню соседней стрелки сохраняется отдельным действием.

## What Changes

- Композиционный диалог с поиском и двумя разделами: «Мои скрипты» и «Встроенные → Теханализ».
- Добавление доступной записи без отключения при повторном выборе; недоступные записи с причиной.
- Русский и английский интерфейс, клавиатура и мобильная полноэкранная компоновка.

## Capabilities

### New Capabilities

- `indicator-library`: выбор доступных индикаторов через локальную библиотеку.

### Modified Capabilities

Нет.

## Impact

Только новые компонент, чистая модель поиска, helper локализации, CSS и тесты. Подключение основной
кнопки и стрелки, математика, параметры и экземпляры индикаторов принадлежат интегратору. Транспорт,
профиль и существующие 13 native интервалов не меняются. Новых зависимостей нет.
