# Spec Delta

## Purpose

Позволяет находить и добавлять доступные индикаторы через локальную библиотеку с двумя понятными
разделами и без вымышленных результатов расчёта.

## ADDED Requirements

### Requirement: Restricted local library

Библиотека SHALL показывать поиск, «Мои скрипты» и «Встроенные → Теханализ»; выбранный раздел SHALL
быть выделен. Поиск SHALL проверять label и aliases локально без учёта регистра.

#### Scenario: Search an alias

- **WHEN** выбран «Теханализ» и введён alias RSI в другом регистре
- **THEN** остаются совпадающие записи этого раздела, а записи «Моих скриптов» не появляются.

#### Scenario: No matches

- **WHEN** строка не совпадает ни с label, ни с aliases выбранного раздела
- **THEN** отображается понятное пустое состояние с возможностью изменить запрос.

### Requirement: Add without toggling off

Доступная запись SHALL вызывать добавление или включение индикатора. Уже активная запись SHALL
оставаться активной при повторном выборе. Недоступная запись SHALL показывать причину и SHALL NOT
вызывать добавление.

#### Scenario: Repeated selection

- **WHEN** пользователь дважды выбирает уже активный MTP
- **THEN** библиотека запрашивает добавление/включение, не отправляя действие выключения.

#### Scenario: Missing calculation

- **WHEN** расчёт записи недоступен
- **THEN** запись отключена, причина видна, клик и клавиатура не добавляют её.

### Requirement: Accessible responsive dialog

Диалог SHALL иметь доступное имя, начальный фокус поиска, Escape и кнопку закрытия, русский и
английский интерфейс. На узком экране SHALL быть полноэкранная компоновка без горизонтального выхода
содержимого.

#### Scenario: Keyboard selection

- **WHEN** пользователь нажимает ArrowDown из поиска
- **THEN** фокус переходит на первую доступную запись, Enter/Space добавляют её, Escape закрывает
  окно.

#### Scenario: Narrow screen

- **WHEN** ширина экрана 375px
- **THEN** поиск, два раздела и прокручиваемый список остаются в пределах полноэкранного окна.
