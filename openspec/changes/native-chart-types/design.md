# Реализация видов графика

## Context

Lightweight Charts предоставляет отдельные нативные серии для четырёх видов. В KLineChart линия
использует режим области с прозрачной заливкой. Оба адаптера получают один набор свечей.

## Decisions

1. Хранить явный выбор в необязательном поле `chartSettings.chartType`. Старые настройки открываются
   со свечами. Чтение не добавляет им поле.
2. Менять тип активного окна отдельной командой, проверяя актуальность после сохранения камеры и
   разметки. Команда объединяет выбор с текущими настройками при записи. Ключ камеры остаётся
   прежним.
3. Пересоздавать нативный адаптер при изменении вида, используя исходную историю и сохранённую
   камеру. Ручной диапазон цены передаётся между адаптерами того же окна и инструмента. Линия и
   область отображают закрытие. Подсказка OHLC, индикаторы и разметка получают исходные свечи.
4. Использовать прозрачную заливку KLineChart для линии и задавать полный градиент для области при
   создании адаптера.
5. Проверять допустимые значения при чтении JSON и снимков Google Диска до импорта. Дополнительные
   окна используют свои локальные настройки.
