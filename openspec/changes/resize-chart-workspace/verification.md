## Результаты

Одинаковый CDP driver планировал72 движения за1200 ms. Записаны фактически полученные page pointer
events и RAF внутри жеста, отдельно от подготовки и остановки CPU profiler. Для MTP ON выполнены 12
жестов, для OFF —6. В OFF отключён MTP, объём остаётся включённым.

| Метрика                                              |        До |    После |
| ---------------------------------------------------- | --------: | -------: |
| RAF p95 с MTP                                        |   36,4 ms |   6,2 ms |
| Полученные pointermove с MTP                         |   636/864 |  863/864 |
| ResizeObserver entries панелей во время одного жеста |   234–330 |        0 |
| RAF p95 без MTP                                      |   30,7 ms |   6,2 ms |
| V8 non-idle в отдельной профилируемой паре           | 2660,8 ms | 571,3 ms |

RAF — измерение cadence callback, не непосредственный замер представления кадра GPU.
Coalescing/недоставленные pointermove сохранены в отчёте и не объявляются плавными кадрами.
GPU-время не измерено. Ранний exploratory driver с последовательным Playwright mouse.move растягивал
жест; он исключён из сравнительной таблицы и сохранён отдельно.

## Нативное поведение и визуальная проверка

- Desktop row: во время удержания размеры всех canvas/панелей неизменны; после отпускания6
  ResizeObserver entries и новая геометрия. Desktop column: после отпускания меняются4 панели.
- Touch-эмуляция392×844 и320×568: во время удержания0 resize, после отпускания меняются2 соседние
  панели. Это не физический Android.
- Предпросмотр удаляется после завершения. Возврат геометрии —0 px. Исходные pane rects и размеры
  всех48 bitmap canvas сравниваемых сцен совпадают. Снимки удержания и результата просмотрены.
- В исходном раннем driver нет per-trial снимка camera: строгая покадровая идентичность camera A/B
  не доказана. После контрольного прогона camera сохранена; кандидат восстановил её после12 обратных
  жестов.

Артефакты в основном checkout: `artifacts/mtp-grid-resize-benchmark/comparison.json`,
`manifest.json`, исходные profiler/RAF/native-events файлы. Просмотрено15 из19 снимков. Исключений
pageerror не было; полный исторический console stream не записывался.

18 целевых unit/interaction/layout тестов прошли, строгие типы и production build прошли;
независимое статическое ревью — PASS. Общие проверки объединённого кандидата фиксируются отдельно.
Вертикальный зум и длинная история с полным MTP640 — отдельные незавершённые измерения.
