## Context

Рабочая область размещает графики в сетке. Несколько рядом стоящих панелей могут пользоваться общей
границей, а на узком экране графики расположены друг над другом.

## Goals / Non-Goals

**Goals**

- Изменять ширину и высоту панелей перетягиванием видимой границы.
- Сохранять минимальные размеры соседних панелей и поддержку клавиатуры.

**Non-Goals**

- Перенос пропорций между устройствами.

## Decisions

- Совпадающие границы нескольких рядов перемещаются совместно. Промежуточные треки перераспределяют
  размер в обе стороны от границы, сохраняя суммарный размер и положение остальных границ.
- На телефоне соседние панели делят фиксированную сумму высот. Вертикальная прокрутка рабочей
  области остаётся доступной.
- Размеры хранятся по владельцу, идентификатору раскладки и режиму экрана.
- При pointerdown считывается исходная геометрия. Pointermove вычисляет ограниченные размеры и
  перемещает только линию предпросмотра через transform; сетка и native chart surfaces сохраняют
  размеры. Pointerup применяет последнюю координату один раз. Cancel/lostcapture применяют последний
  предпросмотр без использования координат отмены. Finalizer освобождает active drag до
  releasePointerCapture, чтобы событие lostcapture не повторяло commit.
- Cleanup сохраняет pending только по исходному ключу; он не переносит геометрию в новую область.
  Клавиатура действует сразу вне pointer drag. Движение без изменения размеров не требует записи.

## Evidence

Профиль production 0.3.44 для сетки 6-balanced показал 3741 ms self в getClientRects после изменения
размеров native canvas, 1390 ms в callback ResizeObserver панелей индикаторов и 1149 ms в расчёте
оптимальной ширины ценовой оси. Профиль содержит 7460 ms idle и работу расширения React DevTools:
эти времена не приписываются вычислениям приложения. Причина forced layout требует отдельного
Performance trace; CPU sampling доказывает только указанные пути. Артефакты:
artifacts/mtp-vertical-benchmark-session/offline-attribution/ в основном checkout.

## Risks / Trade-offs

- На маленьком экране граница смещается в пределах, которые оставляют соседнюю панель видимой. При
  переходе между настольной и узкой компоновками возвращаются размеры соответствующего режима.
- Во время перетягивания содержимое графиков сохраняет прежний размер; пользователь видит линию
  будущей границы. Финальное изменение размеров по-прежнему выполняет штатный каскад native resize.
