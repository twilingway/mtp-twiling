# Spec Delta

## ADDED Requirements

### Requirement: Period averages start from known candles

VWAP и TWAP SHALL начинать накопление с подтверждённой первой свечи периода. VWAP SHALL взвешивать
цену по объёму, а TWAP SHALL усреднять цену наблюдаемых свечей одинакового интервала.

#### Scenario: New period

- **WHEN** вход содержит свечи двух периодов и переданы отметки их начала
- **THEN** цена и вес первого периода не попадают в расчёт второго

#### Scenario: Missing start or volume

- **WHEN** отметка начала периода отсутствует либо у VWAP нет наблюдений с положительным объёмом
- **THEN** расчёт явно сообщает причину отсутствия значений

### Requirement: Automatic VWAP selects one anchor

VWAP с автоякорем SHALL начинаться с последней подтверждённой границы или с последнего экстремума в
заданном окне. Цена расчёта SHALL оставаться независимой от показателя выбора экстремума.

#### Scenario: Repeated maximum

- **WHEN** максимум High встречается в окне несколько раз
- **THEN** накопление начинается у самого позднего максимума

### Requirement: Visible average uses the supplied viewport

Средняя цена SHALL учитывать доступные значения выбранного поля на видимых свечах, включая обе
границы переданного диапазона.

#### Scenario: Chart pans

- **WHEN** изменились границы видимых свечей
- **THEN** расчёт заново усредняет цену по этому диапазону

### Requirement: Plot displacement preserves calculation timestamps

Ишимоку и Аллигатор SHALL возвращать значения в порядке расчётных свечей и сообщать смещение каждой
линии в барах. Данные свечей SHALL использоваться только по текущий расчётный бар включительно.

#### Scenario: Append a live bar

- **WHEN** к серии дописана новая свеча
- **THEN** ранее рассчитанные значения сохраняются, а линии сохраняют направление смещения
