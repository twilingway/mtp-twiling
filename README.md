# mtp.twiling.ru — личный терминал

Браузерный терминал на React и TypeScript для российского рынка. Два движка графика: TradingView
Lightweight Charts 5.0.9 и KLineChart 9.8.12. Интерфейс и управление постепенно приводятся к
привычному TradingView.

## Запуск

Node.js 22.21+ и pnpm 10.34.5:

```powershell
cd D:\MySource\ReactJS\tradingview-personal
pnpm.cmd install --frozen-lockfile
pnpm.cmd dev
```

Открыть http://127.0.0.1:5210/, нажать «Подключить API» и указать собственный ключ Т‑Инвестиций. Для
котировок достаточно токена только для чтения из реального контура.

## Данные и хранение

Браузер напрямую обращается к REST и WebSocket Т‑Банка. Сервер раздаёт только статическое приложение
и обновления; ключи и котировки через него не проходят. У каждого пользователя собственный токен.

Ключ сохраняется по выбору пользователя на устройстве: AES-GCM и неэкспортируемый CryptoKey в
IndexedDB. Выход удаляет сохранённый ключ этого профиля браузера; отзыв в самом банке выполняется
отдельно. Один origin и профиль браузера разделяют локальное хранилище между своими вкладками.

История свечей хранится в IndexedDB, по инструменту и таймфрейму; график дозагружает отсутствующие
диапазоны при прокрутке влево. В настройках доступны объём хранилища и очистка истории. Рисунки и
изображения сохраняются по аккаунту и инструменту, общие для двух движков. Индикаторы общие для всех
инструментов. Настройки, рисунки, изображения и при желании историю можно
экспортировать/импортировать; токен в резервную копию не включается.

`.env` используется только для локальной диагностики. `.env`, `.secrets`, профили браузеров и
артефакты не входят в Git, сборку или релиз. Старые серверные ключи из `.secrets` приложению не
нужны.

## Возможности

- Реальные котировки, изменения, сортировка и поиск по вхождению с debounce.
- 13 нативных интервалов: 1/2/3/5/10/15/30 минут, 1/2/4 часа, день, неделя и месяц; поток
  обновлений, локальная история и избранные интервалы в верхней панели.
- SMA, EMA, объём и MTP160 / MTP160+440 / MTP160+440+640 из Pine Script пользователя.
- Линии, лучи, Фибоначчи в обоих движках; дерево объектов, скрытие, блокировка и порядок слоёв.
- Настройки Фибоначчи: уровни, цвет/толщина/стиль, фон, подписи, координаты, видимость и шаблоны.
- PNG/JPEG/WebP/GIF до 20 МБ с перемещением и изменением размера; Blob хранятся локально.
- Настройки цветов тела/границ/фитилей свечей и прозрачности индикаторов.
- Русский/English, тёмная/светлая темы, выбор IANA-часового пояса; по умолчанию Москва.
- Установка PWA доступна по предложению браузера. Для Т‑Банка на Android есть
  [инструкция по сертификату](public/android-certificate.html).
- Кэш оболочки для работы офлайн. Версия проверяется при открытии вкладки, возврате к ней и раз в
  минуту. Новая версия показывает уведомление и применяется по кнопке после сохранения данных.

Пустые цены не заменяются демонстрационными. Газовый фьючерс NG — конкретный ближайший контракт, не
непрерывная склейка NG1!. IMOEX — индекс Мосбиржи; MOEX — акция биржи. Торговые операции не
реализуются.

## Проверки

```powershell
pnpm.cmd check
pnpm.cmd spec:validate
```

Исходники находятся в `src/`; `public/*.js` и `public/assets/` генерируются сборкой. Релизный список
файлов создаётся в `.release-assets.json`. Нельзя восстанавливать canonical `src/` из устаревших
staging.

## Дальнейшая работа и публикация

Ошибки и предложения: [GitHub Issues](https://github.com/twilingway/mtp-twiling/issues).

Актуальная очередь и границы готовности находятся в [TASKS.md](TASKS.md), передача контекста — в
[HANDOFF_NEXT_SESSION.md](HANDOFF_NEXT_SESSION.md). Google Cloud OAuth и Drive API настроены;
синхронизация с личным Диском пользователя ещё не реализована. Планируются настройки, списки,
разметка и изображения; банковский ключ и кэш свечей остаются на устройстве.

Основной домен: https://mtp.twiling.ru/ (VDS); тестовый: https://mtp-test.twiling.ru/ (Mac mini). На
25.11.2026 публикация ещё не выполнена. Домены — разные origins с отдельными локальными базами. Для
CI/CD подготовлены GitHub Actions и pull watcher с атомарным статическим релизом и откатом: см.
[инструкцию публикации](docs/deployment.md). Старые файлы `deploy/` с Node-backend и маршрутом
`/quotes/` устарели; новый сервис использует только `deploy/static/` и сохраняет соседние
приложения.

## Библиотеки и референс

Lightweight Charts™ и KLineChart распространяются по Apache 2.0. Лицензии и атрибуция включаются в
сборку; см. [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md). React — MIT.

TradingView Advanced Charts не используется. Доступный клиентский JavaScript и авторизованная
страница TradingView изучаются как референс поведения; приложение реализует собственный интерфейс.
