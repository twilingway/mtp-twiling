# Публичная конфигурация OAuth

Приложение использует PKCE без client secret. Client ID берётся только из ENV во время сборки или
запуска DEV; встроенного значения в коде нет. Без `MTP_PUBLIC_YANDEX_CLIENT_ID` Яндекс Диск
показывает, что подключение не настроено; терминал и Google Диск работают независимо. Создайте
игнорируемый `.env` или `.env.local` в корне проекта по образцу `.env.example`:

```dotenv
MTP_PUBLIC_YANDEX_CLIENT_ID=5eb8206c526a4c5593716703d091fa8d
MTP_PUBLIC_YANDEX_REDIRECT_URI=http://localhost:5290/__dev/app/yandex-callback.html
```

Приоритет каждого значения: внешнее окружение процесса → `.env.local` → `.env`. Пустое явно заданное
значение также имеет приоритет. Загрузчик выбирает только две публичные переменные и не изменяет
окружение процесса.

Поддерживаются также `http://127.0.0.1:5290/__dev/app/yandex-callback.html`,
`https://mtp-test.twiling.ru/yandex-callback.html` и `https://mtp.twiling.ru/yandex-callback.html`.
Redirect URI должен совпадать с origin приложения. Без переопределения callback определяется по
адресу приложения.

Только эти две публичные переменные попадают в браузерную сборку. Любые другие ENV-переменные,
включая секреты, не сериализуются этим механизмом. Не добавляйте `.env` и `.env.local` в Git. После
изменения ENV нужна новая сборка или перезапуск DEV. Сами ENV-файлы не раздаются.
