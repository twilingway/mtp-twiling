## Проверено локально

- Нативный общий блок цены/таймера и метки объектов, обе шкалы, изображения без polling.
- Общий горизонтальный масштаб/right gap между TF одного окна, независимость окон.
- Плотный MTP: на телефоне реальные 15083 свечи. Вертикальный Fit остаётся около 50 мс с МТП и без
  него. Ранние normal-X timings не являются доказанным camera-pan FPS: часть жестов двигала только
  crosshair. Новый fast-first-move тест на `d8a1f58` доказал движение камеры и корректное покрытие
  соседней области, но не измерял FPS. Холодный Fit и native overdraw ещё дороги.
- Кеш МТП ограничен захваченной областью, сохраняется между жестами и обновляется за её границей.
  Целевой запас — до одного экрана с каждой стороны; на высоком телефоне около половины экрана из-за
  лимита 16 MiB. Исторический SMA prefix и прогрев до 640 баров сохранены.
- Изоляция quote/candle подписок на `8c852fd`: 20 quote событий дают 0 commits статичных компонентов
  и 20 Watchlist; 20 candle событий не обновляют проверенные статичные компоненты/Watchlist. Это
  React Profiler с реальными функциями и отброшенной разметкой, не замер browser FPS.
- Быстрый dev: CSS/TS autoreload, без SW, отдельные выходы, запуск/остановка проверены.
- Независимые цвета OHLC баров light/dark, Auto/custom/cancel — desktop и телефон, оба движка.
- Мобильный UI на `1d70b1f`: header 46, rail 52, кнопки/аватар 44×44 на общей оси, горизонтальная
  прокрутка, compact Welcome около 346 px. Независимый browser delta 17/17 и физический Android.
- Рисование одним touch-drag, удержание без ПКМ, крупные точки, плавающий editor и меню через «…»;
  масштаб Y обоих движков в двух окнах, обычная прокрутка сетки и отмена KLine без потери autoscale.
  Текущее пользовательское состояние — один segment после ручного удаления второго рисунка;
  настройки и исходная камера после последнего замера восстановлены точно.
- История видна внутри каждого графика, в том числе одного: native select на телефоне 40,545 px.
  Первый тап вне меню объекта закрывает только меню, сохраняя выделение и положение редактора;
  второй пустой тап снимает выделение. Escape также сохраняет выделение и редактор.
- На `8892fac` телефон и отдельный Chrome подтвердили: ZoomOut сам включается после поздней
  готовности native view. После нажатия масштаб действительно уменьшается; смена TF и повторное
  подключение сохраняют работу кнопки. Реальные quote/candle ticks не публикуют ready-сигнал.

## В реализации и проверке

Активная задача — `cloud-storage-retention` в `artifacts/mtp-cloud-retention-release`, база
`61b4c87`. Google: проверяемый raw-архив в облаке, восстановление архивных зависимостей и удаление
только точных сохранённых версий. Яндекс: общий режим Testing и физическое ограничение файлов после
завершения совместимой записи/очистки; неизвестные результаты и конфликты сохраняются. До проверки
raw-архива, v3, compaction record и условного DELETE пользовательские файлы не удалять. После
облачного этапа — PR/зелёный CI/main/проверка публикации, затем новые замеры вертикальной шкалы.
Остальные фигуры и полный portable layout не являются условием этого согласованного выпуска.

Итоговый документальный срез облачного кандидата — 0.3.44, buildId `388541d2eb4bc40f`. Код
подтверждён CI #74: 2390 тестов, 27 проверок публикации и 126 проверок OpenSpec без ошибок, 4
необязательных бенчмарка пропущены. README внутри `src` меняет buildId без изменения поведения.
Google: 179 старых физических файлов удалены после проверки raw-архива, v1/v2 теперь пусты; 20
инструментов и 2 рисунка сохранены. Скачанный raw-архив восстановил все 87 исторических версий без
физического fallback. Яндекс: три сохранения реального набора оставили два независимо прочитанных
файла; оба соответствуют исходным данным, pending/staging/probe — 0. Подробности, пауза с успешным
возобновлением и границы evidence — в `openspec/changes/cloud-storage-retention/verification.md`.
Осталось слияние PR #29 и проверка публикации точного main SHA. Только затем — профилирование
вертикального кадра.

Текущая проверенная база — `bd9b64a`, DEV 5290 в `artifacts/mtp-pixel-render`. Общая проверка: 2227
pass, 4 optional benchmark skip, 0 fail; OpenSpec 124 pass. Native culler проверен в терминале на
Android и отдельном desktop Chrome; длинный Y-кадр около 1,1 с сохраняется, подробности и
ограничения в `docs/NATIVE_CANDLE_RASTER.md`. Календарный кеш проверен отдельно и в приложении (8/8
hits), причинный FPS-выигрыш не заявляется. Google автоматически проверяет запись, сохраняет допуск
на устройстве и адресно удаляет свои технические файлы; реальный Chrome подтвердил reload без
повторной ручной пробы.

Новая локальная реализация — `cloud-version-clarity` в `artifacts/mtp-cloud-clarity`: Яндекс первым,
крупное сравнение версий и дат, независимые отправка/получение, read-only проверка версий.
Перестановка карточек не меняет флаги подключения или автоматического обмена. Физический телефон
после завершения проверки потерял debug transport (1006); helper завершён, новое подключение не
создавалось. Новый UI проверен в изолированном Chrome: 14 fixture-сценариев и actual app smoke в
четырёх размерах. `pnpm check`: 2275 pass, 4 optional benchmark skip, 0 fail; OpenSpec 125 pass.
Направленные операции проверены на тестовых данных, без отправки настоящего workspace.

1. Единый device workspace: не терять инструменты при public→Google→API или logout; COW источники.
   Core и flow проверены отдельно (160 dependent cases); общая база облачных задач —
   `artifacts/mtp-cloud-sync-workbench`, ветка `feat/cloud-sync-workbench`. Общая проверка:
   `pnpm check` — 2147 pass, 4 optional benchmark skip, 0 fail; OpenSpec — 120 pass. Работающий DEV
   5290 переключён на `70a2c6e`; временный 5291 остановлен. Физический телефон подтвердил COW
   миграцию и реальный вход/выход Т-Банка без смены device owner: инструмент, настройки,
   единственный рисунок и timestamp-якорь камеры сохранены. Загружены 15094 реальные свечи;
   remember=false не сохранил банковский credential (проверены только количества записей vault).
2. Google v3: интеграция current+previous в одном файле клиента, реальные CAS/CORS проверки,

3. Яндекс: интеграция PKCE/app-folder transport и immutable ревизий, реальные вход/upload/readback.
   OAuth-приложение зарегистрировано, секрет не получался; публичный Client ID настроен.
4. Общий cloud host/UI: независимое отключение Google и Яндекса без баннеров отключённого сервиса,
   единая очередь импорта и точная revision после commit; ENV только для публичной конфигурации.
   Яндекс Client ID теперь только ENV, без runtime fallback; внешнее ENV > .env.local > .env. Google
   cross-tab fence проверен независимо: отключение или смена аккаунта отменяет подготовленный
   импорт.
5. Новые варианты favicon с буквальным графиком и плотным веером МА; первая абстрактная серия
   отвергнута; крупные варианты V3 готовы к выбору.
