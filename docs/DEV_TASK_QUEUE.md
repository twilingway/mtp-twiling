Обновлено 27.11.2026. По прямому указанию пользователя main/merge/deploy запрещены до завершения

## Проверено локально

- Нативный общий блок цены/таймера и метки объектов, обе шкалы, изображения без polling.
- Общий горизонтальный масштаб/right gap между TF одного окна, независимость окон.
- Плотный MTP: на телефоне реальные 15083 свечи, Fit/оси/pan, p95 около67мс; холодный кадр ещё
  дорог.
- Быстрый dev: CSS/TS autoreload, без SW, отдельные выходы, запуск/остановка проверены.
- Независимые цвета OHLC баров light/dark, Auto/custom/cancel — desktop и телефон, оба движка.
- Мобильный UI на `1d70b1f`: header 46, rail 52, кнопки/аватар 44×44 на общей оси, горизонтальная
  прокрутка, compact Welcome около 346 px. Независимый browser delta 17/17 и физический Android.
- Рисование одним touch-drag, удержание без ПКМ, крупные точки, плавающий editor и меню через «…»;
  масштаб Y обоих движков в двух окнах, обычная прокрутка сетки и отмена KLine без потери autoscale.
  Два пользовательских рисунка, настройки и исходная камера восстановлены.

## В реализации и проверке

1. Единый device workspace: не терять инструменты при public→Google→API или logout; COW источники.
   Core и flow проверены отдельно (160 dependent cases); общая база облачных задач —
   `artifacts/mtp-cloud-sync-workbench`, `285f3e4`. Работающий DEV пока не переключён на миграцию.
2. Google v3: интеграция current+previous в одном файле клиента, реальные CAS/CORS проверки,
   проверяемый архив и закрытый план очистки legacy. Живые файлы пока не удалялись.
3. Яндекс: интеграция PKCE/app-folder transport и immutable ревизий, реальные вход/upload/readback.
   OAuth-приложение зарегистрировано, секрет не получался; публичный Client ID настроен.
4. Общий cloud host/UI: независимое отключение Google и Яндекса без баннеров отключённого сервиса,
   единая очередь импорта и точная revision после commit; ENV только для публичной конфигурации.
5. Новые варианты favicon с буквальным графиком и плотным веером МА; первая абстрактная серия
   отвергнута; крупные варианты V3 готовы к выбору.

Google и Яндекс по прямому запросу пользователя отданы независимым исполнителям. Google:
`artifacts/mtp-google-drive-finish`; Яндекс: `artifacts/mtp-yandex-disk-sync`; общие настройки и
host: `artifacts/mtp-cloud-provider-controls`. Контракт —
`mtp-cloud-sync-workbench/artifacts/cloud-sync-contract.md`. Ключи и OAuth credentials в Git не
попадают. Браузерная регистрация Яндекса подтверждена; реальный обмен ещё не заявляется.
