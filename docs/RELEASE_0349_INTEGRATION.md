# Релиз 0.3.49

## Поведение

- Лоадер показывает восходящий зигзагообразный тренд со стрелкой. Линия прорисовывается на месте,
  без прокрутки; reduced-motion оставляет статичный полный тренд.
- МТП захватывает реальные дополнительные бары на 96 CSS px слева и справа, готовит следующий кадр
  до расходования запаса и сохраняет линии при быстром выходе за него. Основной кадр не меняет
  sampling phase и расчёт SMA.
- Дуга использует растягиваемый сегмент эллипса, ручку по нормали и отдельную заливку по хорде.
  Редактирование недоступной точки отклоняется целиком; перенос старых дуг сохраняет исходные якоря.
- Для блокировки видны действия разблокировки, цвет и галочка. Плавающая панель сохраняет положение
  и по умолчанию не перекрывает подпись.
- Добавлены десять текстовых инструментов, inline Save/Cancel, форматирование, таблица с
  независимыми ячейками, размерами строк/столбцов и экранной привязкой. PriceLabel содержит только
  вычисляемую цену; PriceNote отделяет её от многострочной подписи.
- Яндекс разделяет копии по клиентам, показывает конечное состояние удаления и обновляет список
  после подтверждения. Новая публикация следует за изменением пользовательских данных, с debounce
  750 мс и max-wait 5 секунд. Обычная фоновая проверка не создаёт новый снимок.
- Автоматическая очистка legacy/test требует durable proof исходного содержимого. Изменённые данные
  с тем же ID и старые копии без proof сохраняются. Явный выбор версии связывает точное проверенное
  содержимое; обычные текущие версии других клиентов защищены.

## Общий gate и ограничения

Полный CI, strict OpenSpec и последняя ревизия проверяются в
[PR32](https://github.com/twilingway/mtp-twiling/pull/32). Публикация допускается только после
зелёного CI точного head и контрольной проверки готового сайта.

Диагностическое чтение одного пикселя внутри Worker устраняет deferred Canvas interaction, но
добавляло 13–18 мс Worker roundtrip. Новые времена жестов измерялись при параллельной проверке;
вывод об улучшении FPS не делается. Мобильные проверки этого релиза — эмуляция: физический телефон
пользователь забрал. Signpost хранит экранное смещение, а не закрытый TradingView OHLC-percent
алгоритм. Лимиты заголовка 256 KiB и объёма чтения сохраняются; проверка глубины графа не означает
неограниченный размер одной операции очистки.

Профили браузера, изображения проверок, архивы облака, ключи и `.env` в Git не включены.
