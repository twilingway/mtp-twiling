# Срок входа Google

Приложение остаётся полностью клиентским. GIS token model выдаёт краткоживущий access token без
refresh token. `prompt: none` или пустой `prompt` управляют показом экранов нового запроса, но не
создают механизм продления: после expiry новый токен запрашивается по действию пользователя.
Автоматический бесконечный refresh и серверный посредник не реализованы.

Источник:
[Google: Use the token model](https://developers.google.com/identity/oauth2/web/guides/use-token-model).

До исходного expiry вход переживает reload/reopen: токен, срок и scopes зашифрованы общим
non-extractable ключом устройства в IndexedDB vault, привязаны к bank owner и публичному Client ID.
Восстановление начинается после банковской аутентификации, даже если настройки аккаунта закрыты. Оно
не вызывает Google SDK или OAuth popup и не продлевает срок. Нельзя переносить этот вход через
backup/Drive; Google credentials не входят в публичное состояние или логи.

Отключение, банковский logout, expiry и Google 401 удаляют сохранённый вход. Lifecycle teardown
только прерывает handles. При недоступном хранилище текущая сессия работает в памяти с явным
предупреждением. Offline/сетевая ошибка приостанавливают автоматику, сохраняют локальные изменения и
последнюю успешную отметку. Online/focus возобновляют включённую автоматику при действующем входе.
