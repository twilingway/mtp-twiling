# Каталог индикаторов: источник и готовность

`reference/tradingview-indicators/catalog.json` — снимок публичных builtin metadata открытого
TradingView selector от25.11.2026:127 индикаторов,23 стратегии,64 паттерна,8 профилей,2 options.
Имена RU/EN, IDs/версии/категории взяты из полного уже загруженного объекта, включая невидимые
строки. Это не обещание неизменного всемирного каталога для всех тарифов/версий. Приватные,
купленные и community scripts не включены; исходные формулы и input defaults не получены.

В нашем приложении пока работают Объём, SMA20, EMA50 и три пользовательских MTP. Наличие строки в
сохранённом каталоге не означает, что соответствующие расчёты уже перенесены.

Следующий UI этап: привычное окно поиска, встроенные категории и избранное; math engine и источники
данных подключаются отдельно по замороженному общему контракту. Предпочтительный порядок вычислений:
семейство средних, осцилляторы, ATR/полосы/каналы, объём/сессии, pivots и геометрия. Для стратегий,
фундаментальных показателей и автопостроений нужны отдельные данные и сценарии — их нельзя
реализовать переименованием текущей SMA.
