# Точная отрисовка плотных свечей

`OpaqueRectCuller` получает только целочисленные прямоугольники native renderer и номера цветов.
Обратный проход оставляет непересекающиеся пиксели последнего непрозрачного прямоугольника. Рыночные
данные, OHLC, время, расчёт индикаторов и геометрия SDK остаются прежними.

Canvas bridge включён только у основной Candlestick series. Он принимает кадры плотнее одного
физического пикселя на бар при CSS spacing <1; обычный масштаб освобождает буферы и рисуется native.
Нужны identity transform, source-over, alpha=1, sRGB/unorm8 и отсутствие теней/фильтра. Частичная
прозрачность, неподдерживаемый CSS, состояние или превышение бюджета возвращают native путь до
первого изменения canvas. Alpha=0 ничего не перекрывает. Ошибка после начала paint не запускает
повторное рисование. Другие серии, включая прозрачный объём и KLine, не меняются.

Бюджет одного bridge: 4M пикселей bitmap, 16MiB контролируемых typed arrays с учётом старых и новых
массивов при росте, 8M посещений column-words, до 255 цветов, ограниченные команды/фрагменты. Это
предел ресурсов самого ядра, а не общей памяти браузера/GPU. Resize, неподдерживаемый кадр, обычный
масштаб и destroy освобождают ссылки на буферы.

Build plugin проверяет версию 5.0.9 и SHA256 dev/prod entrypoints, затем добавляет opt-in callback
только в памяти сборщика. Оригинальное тело renderer сохраняется. Файлы node_modules не меняются;
обновление SDK требует явного пересмотра hash guards. Plugin входит в buildId, оба DEV contexts и
production builder. Apache headers/notices сохраняются.

## Локальные доказательства

- 12 pure-core, 9 bridge и 6 SDK/plugin тестов, независимое ревью. Исправлены ограничение работы при
  патологическом перекрытии, освобождение после увеличения spacing и invalid CSS fallback.
- 162 реальных Canvas сравнения и 228 проверок: dev/prod, DPR1/2/2.75, 15083 реальные свечи,
  linear/log/inverted, флаги, прозрачность, неподдерживаемые цвета; различий пикселей нет.
- Desktop CPU microbenchmark production: submission median 8,8→6,6мс, p95 10,8→8,1мс. Симметричный
  readback: 18,9→9,6мс. Обычный масштаб: 0,1→0,1мс на пределе разрешения таймера. Proxy и настоящий
  bridge включены в замер; instrumentation отсутствует в timed runs.
- На исходном эксперименте телефон показал 18,5→7,5мс. Это другая реализация и компонентный
  результат; его нельзя выдавать за ускорение production bridge или FPS терминала.

Артефакты вне Git: `artifacts/mtp-native-rect-acceptance/manifest.json`, `report-timed.json`,
`README.md`. Физическая проверка интегрированного приложения проводится отдельно.
