## Копирование и координаты

В TradingView используются ClipboardEvent, `text/html` с `data-tradingview-clip` и текстовый
fallback. Копируются состояние, точки, экранная геометрия, modelId и порядок слоёв; alertId
удаляется. Вставка выделяет созданные объекты и объединяет пачку в одну undo-макрооперацию. В том же
model используется смещение −40 px по Y; между разными инструментами применяется нормализованная
экранная геометрия. Конкретные преобразования зависят от совпадения символа, валюты и единиц цены.

Собственный терминал использует валидируемый формат приложения; HTML сторонних страниц не
исполняется. Копии получают новые идентификаторы, включая syncId изображений. Токен банка и история
котировок в clipboard не попадают. Работа с объектами не должна перехватывать текстовые
выделения/редактирование.

## История отмены

В исследованном UndoStack нет фиксированного числового лимита: обычные массивы push/pop без
capacity/eviction. История существует в памяти layout, не сохраняется вместе с самим графиком и
очищается при загрузке layout. Одна операция движения хранит состояние до/после всего жеста, а новая
операция очищает redo. Не следует заявлять универсальный лимит 100/1000 действий.

В нашем приложении история разметки должна защищаться от смены аккаунта и импорта; команды одного
инструмента не должны применяться к другому. История свечей и секреты не являются undo-снимками.

## Ограничения проверки

Числовые лимиты рисунков и тарифные разрешения TradingView не измерялись. На сайте clone/paste
проверяют возможность создания рисунков и готовность данных. Контекстная вставка через Clipboard API
может требовать разрешения браузера. Полное совпадение всех инструментов рисования пока не
заявляется.
