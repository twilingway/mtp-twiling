# 0.3.24: Keltner Channels

Кандидат в `feat/release-0324` от `main` 0.3.23. Публичное обновление 0.3.22 → 0.3.23 проверено, см.
`RELEASE_0323_INTEGRATION.md`.

## Изменение

Добавлен Keltner Channels: три линии Upper/Basis/Lower и прозрачная заливка между границами.
Настройки: длина 20, множитель 2, источник close, EMA включена, режим Average True Range, длина
ATR 10. Можно выбрать SMA вместо EMA и один из трёх режимов границ: Average True Range, True Range
или Range. Boolean сохраняется как boolean, выбор режима — точная canonical string.

Число вычисляемых TA увеличено с 50 до 51; с объёмом — 52, с четырьмя MTP — 56. Центральные ожидания
дополнены только KC и ключами useExponentialMa/bandsStyle. Старые исторические witnesses, параметры
и принятые математические kernels не меняются. Форматы instances/backup/DB прежние.

## Проверки кандидата

Повторное подключение к Google Диску требует явного выбора, если в каталоге отсутствует ранее
принятый снимок. Пустой каталог показывает явное подтверждение отправки копии в подключённый
аккаунт. После отмены установки PWA кнопка скрывается до следующего приглашения браузера.

Гостевой профиль без выбранного инструмента восстанавливает ранее сохранённые настройки после
перезагрузки. При экспорте и сохранении пустой выбор представляется отсутствием инструмента.

Source registration `caf00f8b73e84102428d13ef1508d320c0bc9157` прошла независимое ревью: 128 scoped
tests, 432 независимых numeric cases и 53 136 comparisons. Четыре сочетания PVO сохранены точно;
checked=false и три варианта границ прошли RU/EN actual-submit probes. Primary KC 35.0 проверен по
HTTPS и SHA256, см. KELTNER_PRIMARY_CAPTURE.json.

Первичная визуальная проверка выявила влияние скрытых рядов KLineChart на точность соседней панели.
Исправление и границы проверки описаны в `KELTNER_VISIBILITY_AND_SCALE.md`. Отключённый plot
исключается из масштаба. Видимый plot с нулевой прозрачностью сохраняет диапазон, заливка сама
диапазона не создаёт.

На `8306dd6`, build `d580a89c9d64b022`, CI прошёл 1177 тестов и 60 проверок OpenSpec. На обоих SDK
проверены 12 сочетаний настроек KC, видимость, заливка, шкала, камера, сохранение 13 прежних
индикаторов и двух рисунков после импорта. Просмотрены 50 кадров. Независимая проверка KLineChart
прошла 143 целевых теста и 12 дополнительных сценариев.

На `43b210d`, build `fa8cea63a938f403`, подтверждено исправление мобильной формы. Для обоих SDK
проверены RU/EN, светлая и тёмная темы на 375 px, форма на 320 px и сохранение после повторного
открытия. Просмотрены восемь кадров. Известное переполнение фоновой страницы на 320 px сохранилось.

На публичной 0.3.23 в отдельном Chrome проверены кнопка установки, отдельное окно и холодный
офлайн-запуск. Для установки использовали команду Chrome DevTools. Системный диалог, обновление
работающей PWA до 0.3.24 и реальные OAuth и Drive проверяются отдельно.

Новые definitions неизвестны старому клиенту. Отдельные Git-source tests используют точный reader
опубликованной .23 (`62a1a36f2409911f6bdb029f37e0bfe14e852489`): он отклоняет все шесть KC
boolean/choice сочетаний с `unsupported-format`, не меняя входные данные. Старые 50 экземпляров
проектируются reader .23 и текущим reader точно одинаково. Это проверка pure reader, а не реального
Google или синхронизации двух устройств. Новых writer formats или DB migration этот кандидат не
вводит; G5 proposal остаётся отдельным.
