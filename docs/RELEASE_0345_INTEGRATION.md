# Кандидат 0.3.45

## Изменения

- Изменение размеров сетки: во время жеста перемещается допустимая граница предпросмотра; размеры
  native графиков применяются после отпускания. Инструменты, рисунки и настройки сохраняются.
- Меню аватара: котировки и дерево объектов сверху; отдельные группы рабочей области, оформления,
  аккаунта/данных и помощи. Сохранены один аватар, PWA install leaf, guards и навигация
  desktop/mobile.
- Мобильная оболочка ограничена видимой нижней границей окна, учитывает safe-area и активный баннер
  синхронизации. Поиск часового пояса сохраняет фокус при уменьшении видимого окна; Escape закрывает
  сначала внутренний список, затем меню.
- Яндекс: один проверенный контейнер current+previous на клиента; восстановление exact published
  pending без импорта поверх нового локального черновика; свежие enabled/automatic в старых
  вкладках.
- Поиск: дополнительные цены для найденных фьючерсов и публичных инструментов по точному
  UID/provider.
- Блокировки: левая панель отражает выбранный объект, согласована с деревом и отделена от
  глобального закрепления. Переход к мобильному меню сохраняет выделение.

## Проверки

Production-кандидат `b6123d56ef6aab40`: форматирование, ESLint, TypeScript, build, целевые tests и
127 OpenSpec проверок прошли. Полная промежуточная проверка `9d6d809d2bf6183a`: 2456 PASS, 4
optional benchmarks SKIP, 2 FAIL в существующих SSR locale-interface tests. Причина — прямое
обращение меню к window.matchMedia; переход на существующий useMobileLayout исправил обе проверки.
Исходные locale tests не ослаблялись. Финальные source changes также прошли независимое ревью.
Полная финальная проверка CI на точном SHA требуется перед публикацией.

Изолированный визуальный smoke: 34 просмотренных снимка. Матрица desktop1440/1718, mobile320/392,
dark/light и viewport fixtures LW/KLine проверена на `9d6d809d2bf6183a`. Три финальных retake на
`b6123d56ef6aab40` подтвердили видимость Tokyo input при visual height430 без перефокусировки,
вложенный Escape и изменение навигации при переходе через mobile breakpoint. Старые снимки не
приписываются новой сборке. PWA standalone и экранная клавиатура проверены как явно обозначенные
фикстуры; физический Android оставлен спящим по указанию пользователя.

Сравнительный замер grid resize описан в `openspec/changes/resize-chart-workspace/verification.md`:
на одной сцене шести графиков RAF p95 с MTP36,4→6,2 ms, без MTP30,7→6,2 ms; во время жеста0 resize
entries. Эти числа относятся только к изменению размеров сетки, не доказывают ускорение
вертикального масштаба или телефона.

Реальная очистка Яндекса выполнена отдельно:5 физических контейнеров→2, по2 восстанавливаемые версии
для обычного клиента и Testing; архив независимо проверен. Локальные pending/association при очистке
не переписывались. Live recovery после установки новой версии остаётся отдельной проверкой. Private
artifacts, профили браузера, архивы и .env не входят в Git.
