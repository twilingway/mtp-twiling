# Высота карточки инструмента

Разделитель перемещает всю карточку под списком котировок. Мышь и касание используют Pointer
Capture; ArrowUp/Down меняют высоту на 10px, Home/End выбирают допустимые границы. Линия серая 3px,
область захвата 8px, без синего hover.

Настройка владельца `rightDetailsHeightRatio?: number` хранит долю 0.15–0.85, стандарт — 0.45. Поле
optional, schemaVersion остаётся 1. IndexedDB, JSON backup и Drive сохраняют поле существующим
механизмом. Смена viewport ограничивает только отображение и не перезаписывает предпочтение.
Раскрытие/сворачивание статистики не меняет высоту.

Обе области имеют независимую прокрутку. На коротком экране ограничитель учитывает шапку, поиск,
счётчик и подпись; в экстремально низком окне список целиком тоже может прокручиваться.

## Интеграция

Координатор добавляет в `public/index.html` после `instrument-details.css`:

```html
<link rel="stylesheet" href="/watchlist-details-resize.css" />
```

В `Watchlist.tsx` содержательны только import, обёртка `.watchlist-list-region` вокруг списка и
`DetailsDivider` перед `.details.watchlist-resizable-details`. Prettier изменяет отступы;
`git diff -w` показывает точные изменения. Кнопки шапки, SVG и источники цен не менялись.
`AccountDialog`, `GoogleDriveSettings`, общие CSS, `public/index.html` и версия принадлежат
координатору.
