# Облачная синхронизация

В настройках «Облако» первым показан Яндекс Диск. Это рекомендуемый вариант. Подключение и
автоматический обмен настраиваются отдельно для каждого облака.

- **Подключение** предоставляет доступ к выбранному облаку и само по себе не подтверждает обмен.
- **Сравнить версии** читает доступные сохранения и состояние устройства. Проверка не отправляет
  рабочее пространство, не импортирует его и не создаёт технический файл проверки записи.
- **Отправить версию устройства** сохраняет текущие переносимые данные в выбранном облаке.
- **Получить эту версию** заменяет переносимые данные на устройстве выбранным сохранением. Обычное
  получение не записывает разрешение конфликта в облако.
- **Автоматическая синхронизация** запускает существующий обмен без ручного нажатия. При первом
  выборе или конфликте нужна явная версия пользователя; неизвестный результат не считается успехом.

Время **проверки состояния устройства** — время сравнения, а не последняя правка данных. Дата
облачного снимка показывается только при наличии достоверных метаданных. Историческое время
последнего подтверждённого обмена не подтверждает новую проверку или передачу.

Любая направленная передача повторно проверяет локальную ревизию, выбранную облачную версию и
подключение. После изменений старое сравнение требует обновления. При нескольких облачных ветвях
получение одной из них сохраняет остальные и не объявляет конфликт разрешённым.

## Клиент синхронизации

**Этот браузер** сохраняет свой UUID и свои версии. **Тестирование** использует общий тестовый
клиент в выбранном облаке. Для инкогнито или временного сеанса включите «Тестирование» вручную либо
откройте ссылку с параметром `sync-client=testing`. Новый сеанс DEV также выбирает «Тестирование».
Если режим уже сохранён, используется сохранённый выбор.

## Сколько версий хранится

- **Яндекс Диск.** После завершённой очистки у каждого клиента остаётся до двух физических файлов
  нового формата. Последний файл содержит текущую и, если она есть, предыдущую версию вместе с
  изображениями. Старые файлы формата v1, неизвестные файлы и нерешённые ветви сохранены. Если
  запись подтверждена, а очистка ждёт повтора, это показано отдельным статусом. Нажмите
  «Синхронизировать сейчас», чтобы повторить очистку.
- **Google Диск.** Один файл каждого клиента хранит текущую и предыдущую версии. Если показан
  «Перенос старых сохранений», скачайте и проверьте предлагаемый архив, затем выберите версию. После
  подтверждения версии нового формата можно нажать «Сохранить архив и очистить старые файлы».
  Приложение перечитает и проверит архив в облаке, затем удалит только архивированные версии с
  совпадающими метками. При паузе выберите «Повторить очистку». Архивы доступны в настройках Google
  Диска.

Сравнение и обычное получение версии не запускают очистку. Удалять файлы вручную через сайт Диска не
требуется. Сохраните проверенные архивы Google для восстановления и обновите старые версии
приложения после очистки. [Подробности Google](GOOGLE_DRIVE_SYNC.md).
