Нижний реестр содержит **исторические** исходные оценки от 25.11.2026. В частности, строки «Drive не
реализован», «разделы следующий этап», «6 indicator keys» и старые статусы публикации не являются
текущими. Их нельзя использовать как completion evidence; нужны исходники, тесты и подходящий QA.

Цель пользователя: подробно повторить работу котировок, графиков, рисования и панелей в личной PWA
mtp.twiling.ru. Поведение сверяется по текущему клиентскому JavaScript TradingView, состоянию
авторизованной страницы и документации. Совпадение интерфейса не считается доказательством
совпадения поведения. Статус «проверено» требует проверки реализации и подходящего сценария.

На 25.11.2026 исходный layout TradingView и пользовательская вкладка приложения сохраняются.
Публичные JS-модули референса лежат только в игнорируемых локальных artifacts; в приложение
переносится собственная реализация поведения. Общие данные и разметка обслуживают оба движка.

## Порядок ближайшей работы

1. Закрыть текущие проверки таймера, перемещения/масштаба, правой панели и действий дерева.
2. Выполнить ранее запрошенные удаление инструмента и изменение ширины за разделитель.
3. Довести Фибоначчи по подробному аудиту, сохранить незакрытые пункты отдельно от готовых.
4. Расширить интервалы и меню типов графика; общий поиск РФ/крипто после проверки бирж.
5. По матрице продолжить остальные инструменты, меню и настройки; затем синхронизацию/публикацию.

## Правило закрытия пункта

1. Зафиксировать наблюдаемое поведение и источник.
2. Реализовать типы, UI, сохранение/импорт и оба адаптера, где применимо.
3. Проверить значимые граничные случаи, затем интерфейс в отдельном профиле.
4. Обновить статус и доказательства. Наличие кнопки без работающего действия не закрывает пункт.
